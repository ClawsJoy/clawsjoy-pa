# ClawsJoy 客户端 · 净机安装一页纸

（这是给**照抄就能装完**用的。每一节都是三段：**照抄的命令** ⇒ **应该看到** ⇒ **如果不对怎么办**。
不用懂电脑术语；遇到看不懂的，整屏截图发回来即可。）

---

## 〇、开始前，先确认两件事

**1）这台电脑是 Windows 10 或 Windows 11（64 位）。** 家庭版也可以。

**2）电脑上必须装 CPython 3.12（64 位）。** 确认办法 —— 照抄：

    python --version

应该看到 `Python 3.12.x` · 并且是 **64 位**（例：`Python 3.12.10`）。

如果提示「不是内部或外部命令」⇒ 这台电脑还没装 Python。去官网 `python.org` 下 Windows 安装包，
安装第一步**务必勾上** `Add python.exe to PATH`，装完关掉窗口重开，再跑一次上面那条命令。

⭐ **为什么锁死 3.12（64 位）**：这个包里的零件是按 CPython 3.12 · 64 位编好的；
3.10 ／ 3.11 ／ 32 位的机器**装不上**。下载页请选 **Windows installer (64-bit)** 的 **3.12** 版
（⛔ 不要选 32 位、⛔ 不要选别的版本号）。
装好后前置闸会自己核对版本：对不上会**当场用大白话报出来并停下**（⛔ 不会装一半）。

---

## 一、把包放好

把交付给你的**整个文件夹**拷到这台电脑上（例：拷到 `D:\ClawsJoy`）。
⛔ **不要只拷里面的文件**，要连文件夹一起拷。

下面所有命令，都要在**这个文件夹里**执行。打开这个文件夹之后，在地址栏里输入 `cmd` 再回车，
就会弹出一个黑窗口，光标已经在正确位置了。

## 二、先对一遍：包有没有少东西（校验）

照抄：

    python -X utf8 scripts\win_pa\make_client_bundle.py --check .

应该看到两行（第二行五个数都是 0）：

    [核] . ｜ 册 在
      依缺 0 ／ 印缺 0 ／ 印异 0 ／ 印多 0 ／ 活∧组织物 0

如果不对 ⇒ 说明拷贝过程掉了文件：**重新整个拷一次**；仍不对，把整屏文字发回来。

## 三、装上（不联网也能装）

**这一步会问你一句「你的笔记放在哪儿」。** 三种答法，任选其一 —— 都是一行，照抄：

**答法 A：我有自己的笔记文件夹**（把 `D:\我的笔记` 换成你自己的那个文件夹）：

    python -X utf8 scripts\win_pa\install_win_pa.py --offline --go --pip-install --vault-dir "D:\我的笔记"

**答法 B：先不管，用它自带的一个空笔记库：**

    python -X utf8 scripts\win_pa\install_win_pa.py --offline --go --pip-install --skip-vault

**答法 C：什么都不加**，程序会在窗口里当场问你一句：

    python -X utf8 scripts\win_pa\install_win_pa.py --offline --go --pip-install

应该看到：最后没有 `[FAIL]`，能走到装依赖并正常结束。

- **答法 A** ⇒ 程序会把你选的那个文件夹记成「笔记库」；**要关掉这个窗口、重开一个**，下次启动才会用它。
- **答法 B / C（跳过）** ⇒ 它会用**自带的一个空笔记库**（就在你那个文件夹的 `data\kb` 里），马上就能用；
  以后想放笔记，直接往那里放即可，也可以随时按答法 A 另外指定一个。

**⭐ 这个包要装的东西分两块：**
- **必装**：Python 依赖（就在包里 `wheel` 那个文件夹里的零件）—— 用 `--offline` 装，**不联网**也能装上。
- **可选**：本机模型（要它「不连云端也能答」时才要）—— 须另外下载（**要网**）。装不装都不影响先跑起来。

**⭐ 还有一条路（本产品的正路 · 推荐）：装完之后，在页面上选。**

起好、打开首屏（第四、五节）之后，首屏上会有一行「**选一个笔记目录（本机之资料面）**」：
把你想用的那个文件夹的**完整路径**贴进旁边的框（例：`D:\我的笔记`）⇒ 点「**用此目录**」⇒
**当场生效**（不用关窗、不用重开、不用重启程序）。想回到它自带的空笔记库 ⇒ 点「**清除（回退）**」；
暂时先不管 ⇒ 点「**跳过**」。（若首屏上出现一句「本机之库根由环境变量…指定 ⇒ 你所选须清该变量方生效」，
那是给**开发机**看的；给别人用的干净机器上一般不会出现。）

⭐ **两条路之关系（请记住这一句）**：上面那三种答法（**装的时候就指定**）是**装程顺带的便路** ——
它记在「用户级环境变量」里，所以要**关掉本窗、重开一个**才生效；而这里这条「**装完之后在页面上选**」
是**本产品的正路（产品之正形）** —— 点完**立即生效**，也不必记什么环境变量。
**两条都能用**；拿不准就用这里这条。

如果不对 ⇒ 把整屏文字发回来。若屏幕出现 `端口` 字样，说明这台机器上已经有一个在跑，先看第八节关掉它。

---

## 四、启动

照抄：

    python -X utf8 scripts\win_pa\pa_nowindow.py start

应该看到（五行差不多就这些）：

    [OK] preflight passed (rc=0)
    [INFO] gateway port = <端口>  (source: config/system/system_unified.yaml)
    [OK] started pid=<进程号> (no window) at ...
    [OK] console log: ...\logs\gateway_<端口>_console.log
    [OK] door is open now; first-run warmup continues in background

⭐ **把第二行那个端口号记下来**（上面用 `<端口>` 代替，你那里会是一个具体数字，例如 `5102`）。

⚠️ **这个程序不会自己开机就跑**（安装不会把它加到开机启动里）。
**每次想用，都要照这一节手动起一次**；关掉后再用，再起一次。

如果不对 ⇒ 屏幕会出现 `[FAIL]` 并说明哪一条不过（多半是没装 Python、或端口被占）。整屏发回。

⭐ 页面**即刻可开**（门先开 · HTTP 监听先起）；但**首启 2–4 分钟**在后台准备向量模型
（`all-MiniLM-L6-v2` · 约 `79 MB` · **首启须联网下载**）⇒ 页面此时显 **「正在准备」**，**属常**（⛔ 非故障）。
**其后启动为秒级**。⚠ 若断网 ⇒ 向量检索降级并明报，然页面仍可开。

## 五、打开看（首屏）

打开浏览器（Edge / Chrome 都行），在地址栏输入：

    http://127.0.0.1:换端口/web/pa.html

把「换端口」替成你第四节记下的数字，例如：`http://127.0.0.1:5102/web/pa.html`

若页面显 **「正在准备」** ⇒ 等它转「就绪」（**首启 2–4 分钟**；其后**秒级**）；仍打不开则按 F5 刷新一次。

如果打不开 ⇒ 先跑一次这个，看它怎么说：

    python -X utf8 scripts\win_pa\pa_nowindow.py status

## 六、什么样子算「正常」（⭐ 这一节最重要，请先读完再下判断）

这台机器是**给别人用的干净机器**，所以它「看起来功能少」是**故意**的。下面几条都属于**正常**，
⛔ 不要当成「装坏了」：

1. **页面上能点的入口比你想的少。** ⇒ 正常。内部专用的那一批功能在这台机器上本来就是关着的。

2. **问它问题，它回一句「未接」并给出「去选目录 / 去装模型」的去处。** ⇒ 正常，
   而且这正是我们要验的那一种样子：这台机器上没装本地大模型，程序如实说「没接上」，
   ⛔ 不是崩了、也不是装错。
   （演示时走的是**云端** `deepseek-flash`，不靠这台机器的显卡；本地模型只是备选。）

3. **首页会写着一个笔记库的位置（例如 `…\data\kb`）—— 那是它自带的空笔记库。** ⇒ 正常，
   ⛔ **不是「没接上」、⛔ 不是装坏。** 你没有另外指定文件夹时（第三节答法 B / C），它就用这个自带的；
   你可以把笔记直接放进去，也可以另外指定一个（见第三节答法 A）。
   **只有连自带的都没有时，它才会写「未接（选目录）」** —— 交付包里自带一个，所以通常看不到这几个字。
   （空是空，⛔ 不等于是坏。）

4. **有些栏目写着「未接（组织版）」。** ⇒ 正常。这台机器上没有我们的内部资料。

4b. **首屏上写着一句「云端密钥：本机未配（正常 —— 交付包里本来就没有这一件）」。**
   ⇒ 正常。包里**故意不放**密钥文件；本机没配密钥就照实说一句「未配」，
   ⛔ 不会因为少了这个文件就启不起来。（要让它连云端 ⇒ 见文末「附」。）

   ⭐ **密钥有没有 ⇒ 页面显示不一样**：没配 ⇒ 那一行照实写「未配」，答问只能走**本机模型**；
   配了 ⇒ 写「已配」，答问走**云端**（演示主线 `deepseek-flash`），本机模型可**不装**。
   一句话：**没有密钥 ⇒ 本机模型才要装；有密钥 ⇒ 本机模型可选。**

5. **顶上若出现一条黄色小字：「快照读不到 · 版本或暂不可用 ⇒ 本行按「未知」记」，旁边还有一个「⚠ 取数刻未给」。**
   **起完服务之后，这一行不该再出现** —— 程序在**开始服务之前**就会自己把「界面态快照」这个文件落好（见 5b）。
   如果**仍然**看到 ⇒ 多半是**那个文件没写进去**（装到了需要管理员权限的目录）⇒ 照 5b 看服务窗口那一行；⛔ 不是装坏。
   （它**不会**把不知道的东西写成「正常」。）

5b. ⭐ **（跑演示的那一步）想让上面那一行显示真正的读数** —— **服务会自己落一次快照**（起服务时自动写 `web\pa\ui_state.json`）。
   起完服务按 **F5** 刷一下首屏 ⇒ 那行黄字就应变成真读数，并带一句「采样刻 …（快照 · ⛔ 实时）」；⛔ 须人工多一步。
   若仍然是「快照读不到」⇒ 看**服务窗口**（或 `logs\gateway_<端口>_console.log`）里有没有一行 `[UI_STATE] …`：
     · `[UI_STATE] 界面态快照已落（服务自落 …）：…` ⇒ 已经落好了 ⇒ 按 **F5** 再刷一次即可；
     · `[UI_STATE] ⛔ 界面态快照 ⛔ 落（…）：…` ⇒ **写不进去**（多半是装到了需要管理员权限的目录）⇒ 这属**已知貌**
       （界面照旧显「未载入」，**⛔ 不是装坏**）；把那一整句发回给我们即可。
   **时机**：快照在**服务开始服务之前**就已落好（里面含「本地在 ／ 远端态」⇒ 起服务时现场探一次）⇒ 你**不用**掐时机。
   ⚠ **明书（⛔ 免误判）**：ⓐ ⛔ 须任何外部工具 —— 快照由**服务自己**写；我们内部「内容工坊」里那把 `模型_双模.py`
   只是**开发机上的旁证**（⛔ 在交付包内、⛔ 作净机之凭）；ⓑ 快照是**采样那一刻**的读数，**⛔ 不是实时**（要更新 ⇒ 重启服务）；
   ⓒ **⛔ 把别处的快照件拷过来当读数**（那会显示**别的机器**的显存 ／ 云端态 ⇒ 假读数）。
   （第 5 条那种「未知」之貌 —— **起完服务之后不该再看到**；若看到 ⇒ 即上面所列之二支之一，照其办即可。）

另外：如果屏幕上（或页面上）出现一行「**本轮经云端 · 内容将出机 · 模型 deepseek-flash**」，
那是**如实提醒**：这一轮的问题会发到云端去算，而且算完不留内容副本。

## 八、关掉 / 卸载

**先关掉正在跑的：**

    python -X utf8 scripts\win_pa\pa_nowindow.py stop

**卸载（删掉「开机自动跑」的两个计划任务；⛔ 不动任何产品文件）：**

    python -X utf8 scripts\win_pa\uninstall_win_pa.py
    python -X utf8 scripts\win_pa\uninstall_win_pa.py --go

第一条是**空跑**（只告诉你它会删什么），确认没问题再跑第二条真的删。

**如果你第三节里指定过自己的笔记文件夹（答法 A）**，想把那条记录也一起撤掉，就再加一个 `--unset-vault`：

    python -X utf8 scripts\win_pa\uninstall_win_pa.py --unset-vault
    python -X utf8 scripts\win_pa\uninstall_win_pa.py --unset-vault --go

（它只撤「笔记文件夹」那一条记录，**你的笔记文件一个都不会动**。同样先空跑、看一眼，再真删。）

**想彻底清干净** ⇒ 直接把第一节那个文件夹整个删掉即可（程序不往别处写东西）。

⚠️ 关掉**不会**自己再起来；下次要用 ⇒ **照第四节手动再起一次**。

## 附：想让它连云端模型（可选，演示用）

在第一节那个文件夹里的 **`config` 子文件夹**下新建一个名字叫 `.env` 的文件，里面写一行密钥（密钥由我们私下给，⛔ 不要外发）：

    完整路径：`<你那个文件夹>\config\.env`
    DEEPSEEK_API_KEY=拿到的密钥

放好后，**停一次、再起一次**（第八节的 `stop` + 第四节的 `start`）才会生效。
起好后再刷新首屏 ⇒ 那一行会从「未配」变成「已配」。
