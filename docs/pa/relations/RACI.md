# RACI · 外联脚手架 v0

- R=执行，A=最终负责/批准，C=被咨询，I=被告知。
- 原则：一个活动只能有一个 A；PA 不做第二裁判。

| 活动 | 老板 | CEO | PM | PD | CW | PA |
|---|---|---|---|---|---|---|
| 真删/purge | **A** | C | I | R | I | R |
| ① 六拍④外置 | A | **R/A** | I | C | I | R |
| 真 OV/EV / 对外发布 | **A** | C | I | R | I | R |
| 用户角度/判据/40存疑终判 | I | C | **A/R** | C | C | C |
| 版本/签名/根/平台 | I | C | C | **A/R** | I | C |
| 前端/功能/A2 | I | I | C | C | **A/R** | C |
| 任务编排/验收/证据 | I | C | C | C | C | **A/R** |
| 通道 ID/转派 | I | C | C | C | C | **A/R** |
| 生产关系统计/复盘 | I | C | C | C | C | **A/R** |

## 三条硬规

1. 没有 A 的活动，不开工。
2. A 不在场时，PA 只能“备件/候裁”，不能代签。
3. 同一活动出现两个 A ⇒ 先裁 A，再执行。
