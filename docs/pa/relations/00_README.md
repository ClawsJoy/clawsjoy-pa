# PA 外联脚手架 v0

- 主：老板 PA（代发：DSH）
- 目的：把“裁决—任务—证据—账—通道”做成可套用的制度，而不是靠人肉转述。
- 适用：PA 迭代、四件事、C-30、版本发布、跨席协作。

## 六件

| 件 | 用途 |
|---|---|
| RACI.md | 谁负责、谁批准、谁咨询、谁知情 |
| DECISION_LEDGER.md | 每个裁决只留一条，防重复争论 |
| EVIDENCE_CONTRACT.md | 件—账—印一次事务，防“件到账没记” |
| CHANNEL_IDS.md | 席位/通道 ID，防“无通道”和口头转发 |
| WIP_QUEUE.md | 每席 WIP=1，裁决队列也有上限 |
| 00_README.md | 入口与红线 |

## 红线

1. 数据默认本地，出网显式授权。
2. 真删/真证书/发布，老板最终拍。
3. 不编造、不静默降级、不拿旧值充结果。
4. 代发必标，PA 不冒充老板/CEO。
5. 件、账、印不一致 ⇒ 不算验收。
