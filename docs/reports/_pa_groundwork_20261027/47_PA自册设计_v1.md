# PA 自册设计 v1（2026-10-27）

- 主：DSH（PA）｜依据：老板「PA 入自己的册；扫其他 agent 待入册」
- 定位：**PA 是主人侧的 agent 册**；别队册（Paseo／PM／CEO）**只读导入**，⛔ 写回，⛔ 造真席。

---

## 一 四层

| 层 | kind | 内容 | 可派 |
|---|---|---|---|
| self | `self` | PA 自身卡：能力／边界／脆性／成本／invoke／probe | — |
| active | `agent` | 已扫、已探、已批：本机席／CLI／云 API／云 VM／MCP | ✓ |
| pending | `pending` | 扫到但未验／未批；显「待入册」 | ⛔ |
| external | `external` | 别队册只读镜像；仅作来源 | — |

---

## 二 卡（七键 ＋ 五状态）

```
id, kind, name, class, provider,
capabilities[], boundary, fragility, cost,
invoke{cli|http|sdk|seat}, probe{cmd|url}, verified,
approved_by, approved_at, status,
last_run_at, last_receipt, egress_class
```

状态机：`discovered → probed → approved → active`；`active → degraded → retired`。

- `boundary` ／ `fragility` **必填**；⛔ 只写能力；
- `verified` 须有**实测读数＋刻**；⛔ 「应该可以」；
- `pending` 可派 ＝ **False**；
- `external` 只读，⛔ 改。

---

## 三 扫（来源）

| 类 | 法 |
|---|---|
| 本机席 | `paseo agent ls --format json`（id／name／provider／status／cwd） |
| CLI | `shutil.which` ＋ `--version`；`build` ／ `claude` ／ `codex` ／ `dsh` |
| 云 API | provider 配置**只读布尔**（有 key／无 key），⛔ 读值 |
| 云 VM | `~/.ssh/config` 别名 ＋ 一次 `ssh -G`；⛔ 自动连 |
| MCP | 本机 MCP 清单；⛔ 自动信任 |

⛔ 扫 = 发现，⛔ = 信任；扫到一律 `pending`。

---

## 四 探（probe）

- 版本／health／**一次最小调用**；超时 5s；
- 成功 ⇒ `probed` ＋ 读数＋刻；失败 ⇒ 保持 `pending`，附错；
- ⛔ 自动批；⛔ 以「在册」充「可用」。

---

## 五 批（Agents 面）

- 「待入册 N」徽；逐卡：能力／边界／脆性／成本／探读数；
- 老板点「入册」⇒ `active`；点「不」⇒ `rejected`（留痕）；
- 批可带**范围／期**：只读／本机写／出机；
- pending ⛔ 出现在派活选人列表。

---

## 六 派（orchestrator）

- 只从 `active` 选；按 capability／boundary／fragility／cost；
- 派前给出机明书（若涉 L3+）；
- 收：回执 ＋ 成本 ＋ 产物；记 PA 账；
- 失败：降 `degraded`，⛔ 反复重试；
- 停：1s。

## 八 验收

1. 扫 `paseo agent ls` ⇒ 15 席全入 `pending`，**0** 自动 `active`；
2. `pending` 不可派（选人列表不出现）；
3. 批 1 席 ⇒ `active`；probe 读数＋刻在卡；
4. 停用 ⇒ `retired`；⛔ 删痕；
5. `DSH技术复核` 显「待入册·无真席」；
6. 别队册只读：⛔ 写回，⛔ 新席。

## 十 接入顺序 ≠ 入册（关键）

| 问题 | 答 |
|---|---|
| 用哪条路管 | **API/SDK ＞ MCP/本地服务 ＞ CLI ＞ CDP ＞ UIA/截图**；按任务选最稳 |
| 要不要入册 | **席位卡**；**发现广／入册窄／激活批** |
| 一席多路 | **一张卡，多 control_plane／view**；窗是 view，⛔ 另建卡 |
| 未入册 | ⛔ 不派；临时卡须批 |
| 按需 | 发现可广（只读扫）；**激活**按任务、带范围与期；用完可 retire |

例：
- `cli:dsh` 一张卡：control_plane=`dsh-cli`，view=`dsh-web`；⛔ 另建「DSH 窗」卡；
- `cli:codex` 一张卡：control_plane=`codex-cli/app-server`，view=`codex-app/tui`；
- GUI-only 才用 `window:<pid>:<hwnd>`：control_plane=`uia`，fragility=high。

⇒ 顺序是**可靠性偏好**，⛔ 绝对等级；UIA 只在无 API/CLI 时用。
