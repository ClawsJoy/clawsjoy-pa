## 三 解析规则（必须机读，不许手填）

1. **根序**：`_pm` → `codex` → `paseo-pm`；
2. **文件名匹配**：`[_-]<id>([_.]|$)`；
3. **优先级**：先取 `_令_` ／ `_回_` ／ `_报_` ／ `_请_` ／ `_裁_` ／ `_记_` 开头的件；无则取任意命中；
4. **多命中**：取**文档类**中字节最大者，其余记入 `other_hits`（⛔ 静默丢）；
5. **未命中**：`status=missing` ＋ 报红；**⛔ 编造路径、⛔ 指向同名但异号件**；
6. **非独立件**：若 id 只作为某件内的节号出现（例：`2269 §一.2`），`status=非独立件`，`rel_path` 指其宿主件。

## 四 机检判据（可复跑）

| # | 判据 | 检查方式 |
|---|---|---|
| I1 | 条目数 ≥ 代码内唯一 id 数（96） | 扫 `core/pa/*.py` ＋ `web/pa/**/*.js`，取 `pm_([0-9]{3,4})` 去重 |
| I2 | 代码每个 id 都能解析 | 对 I1 的集合做差集；差集非空 ⇒ 红 |
