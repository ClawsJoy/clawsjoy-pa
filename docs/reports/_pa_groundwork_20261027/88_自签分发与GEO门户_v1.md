# 自签分发＋GEO门户方向 v1（2026-10-29 00:0x）

- 令：自签免费给用户；将有一个 GEO 网站连接用户本地分布式 PA
- 判：**自签仅可信早期用户；GEO 门户须做设备身份/配对，不靠代码签名；公开分发仍建议真证书。**

## 一 已定

- 我们签：内部证书 CN=ClawsJoy Internal；
- 用户只导入公钥 `.cer`；绝不发 PFX；
- 导入脚本：`scripts/win_pa/install_internal_cert.ps1`（验指纹→Root＋TrustedPublisher）；
- 当前 9.0.16 已签；本机导入后 `Get-AuthenticodeSignature=Valid`；
- **仍不解 SmartScreen**。

## 二 自签适用边界

- 适合：内测、自有机器、公司内网、可信早期用户；
- 不适合：公开下载站/陌生用户；
- 原因：
  1. 用户须把自签根证书放进 Root ⇒ 私钥泄露即全信任链失守；
  2. 需管理员；
  3. SmartScreen 仍拦；
  4. 每台机器重复导入。

## 三 GEO 门户（按“地理分布/全球门户”理解）

- **控制面**：账号、设备登记、配对、权限、撤销；
- **数据面**：本地 PA 持有数据；默认不上传；
- **连接**：一次性配对码/QR ⇒ 每设备密钥对 ⇒ 双向认证/短期令牌；
- **传输**：端到端加密；必要时中继，云端只见最少元数据；
- **信任**：门户连接信任靠设备密钥/证书，**与 exe 代码签名无关**；
- **合规**：隐私政策、出机提示、可撤销、审计。

## 四 成本

- 自签：0；
- 门户 HTTPS：Let's Encrypt 0；
- 公开分发若不想让用户装根证书：Azure Trusted Signing Basic 约 $10/月，或 OV 约 $200–400/年；
- 免费用户规模上来后，自签导入的客服/安全成本 > 证书费。

## 五 下一步

1. 证书导入脚本随包/单独分发；
2. GEO 门户先做设备配对/身份/撤销，不做数据汇聚；
3. 公开分发前评估 Azure/OV；
4. Program Files 装级仍待 UAC。
