## 三 PA 入册：**入自己的册** ✓

你说得对：**PA 不进别队的席册；PA 有自己的册。**

| 层 | 内容 | 可派 |
|---|---|---|
| **self** | PA 自身卡（`kind:self`）：能力／边界／脆性／成本／invoke／probe | — |
| **active** | 已验已批的 agent：本机席／CLI／云 API／云 VM／MCP | ✓ |
| **pending** | 扫到但未验／未批：`verified:false`，显「待入册」 | ⛔ |
| **external** | 别队册（Paseo／PM／CEO）只读导入，⛔ 写回 | — |

### 流程

1. **扫**：`paseo agent ls`／`which`＋`--version`／provider 配置／SSH 配置／MCP；
2. **探**：`probe`（版本／health／最小调用）＋刻；
3. **批**：老板在 Agents 面批；⛔ 自动信任；
4. **入**：`active`；`pending` 一直可见但不可派；
5. **退**：停用／删除卡；⛔ 删痕。

⇒ `DSH技术复核` 在本册是 **pending external identity**（`verified:false`，`boundary: 无真席`），不是 C-30 席；3402 留档即可。
