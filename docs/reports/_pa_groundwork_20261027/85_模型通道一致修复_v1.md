# 模型名/通道不一致 400 修复 v1（2026-10-28 23:3x）

- 现象：9.0.15 发问 ⇒ DeepSeek API 400：支持 deepseek-flash/v4-pro，却收到 qwen2.5:7b；
- 根因：DeepSeek key 已配 ⇒ 默认通道 remote:deepseek；但模型选单回填了旧存底 qwen（本机 Ollama 模型），qwen 名被发给 DeepSeek；
- 判：**模型选单须与默认通道同源；存底跨通道 ⇒ 不采用。**

## 修

- `web/pa/faces/config.js` `paModelRender`：存底模型若 `provider_id ≠ d.default.provider` ⇒ 不采用，改选默认通道之模型；
- 显形注：「默认通道已切 ⇒ 已按默认通道选模」；
- 实测：`#cfgModel` -> **deepseek-flash**；真发「你好」-> `src: remote:deepseek:deepseek-flash`，回执有，无 400。

## 边界

- 9.0.15 包**未含**此修；需 9.0.16（或重发 9.0.15）。
- 当前安装已热拷 config.js；F5 后生效。
- 手动也可在设置里把模型改成 deepseek-flash。
