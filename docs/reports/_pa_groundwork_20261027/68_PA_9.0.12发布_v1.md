## 三 签名（如何签）

### 现状

- `Cert:\CurrentUser\My` 无 CodeSigning 证书；无 CSC_LINK/CSC_KEY_PASSWORD；
- 安装器/ClawsJoyPA.exe 均 **NotSigned**；SmartScreen 会报“未知发布者”。

### 正解（二选一）

**A. 买/取 OV/EV 代码签名证书（推荐）**

1. 得 `.pfx` ＋ 口令（或 EV 的 HSM/云签）；
2. 构建：`set CSC_LINK=D:\path\cert.pfx` ＋ `set CSC_KEY_PASSWORD=...`；`cd shell && npm run dist`；
3. 或手签：
   `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /f cert.pfx /p <pwd> /a ClawsJoyPA-Setup-9.0.12-x64.exe`
   （signtool 在 `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\...\x64\signtool.exe`）

**B. 内部自签（仅内测，不解决 SmartScreen）**

```
$c = New-SelfSignedCertificate -Type CodeSigningCert -Subject 'CN=ClawsJoy Internal' -CertStoreLocation Cert:\CurrentUser\My
Export-PfxCertificate -Cert $c -FilePath D:\clawsjoy_internal.pfx -Password (ConvertTo-SecureString 'pass' -AsPlainText -Force)
signtool sign /fd SHA256 /f D:\clawsjoy_internal.pfx /p pass /a <setup.exe>
```

- 只对**信任该证书**的机器有效；⛔ 对外发布；
- 不能替代 CA 证书。
