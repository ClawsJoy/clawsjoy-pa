### 时长分布规律
- **学习方法类**：21-45 分钟中长视频（理论+案例），爆款 30 分钟上下
- **考研刷题类**：两极分化——短干货（3-7 分钟"速成/避坑"）vs 长带背（1.5-7.5 小时"浓缩/带刷"）
- **AI 工具类**：普遍 <15 分钟（教程/演示）
- **结论**：教育类爆款集中在 **3-7 分钟（快干货）+ 20-45 分钟（深度方法论）** 两个区间

### 标题规律（数字/悬念/干货）
1. **数字冲击**：142分 / 1000题 / 100倍 / 300% / 100道
2. **悬念反问**：学了就忘？？？/ 谁说努力没用？/ 学习比游戏还爽100倍？
3. **干货承诺**：浓缩版/精华/底层规律/避坑/方法论
4. **身份背书**：北大刘媛媛/清华博士/武忠祥/赖世雄/142分
5. **情绪词**：直接背！/努力有用/效率暴涨/拒绝无用功

### 画面风格推断（基于标题/UP主类型，未逐帧验证）
- 理论类（硬核学长2077）：**文字卡片 + 动画演示**（高效学习底层规律）
- 经验分享类（橙子学姐/一斤也不欠）：**真人实拍 + 字幕强调**
- 资料带背类（学长小谭/辉哥）：**PPT/讲义录屏 + 激光笔标注**
- 工具教程类（Winter喵）：**录屏 + 代码窗口 + 配音**
- 结论：**文字卡片 + 录屏标注**是教育类主流（低成本高信息密度），真人出镜提升信任

### 开头 3 秒抓人规律（推断）
- 抛出结果/成绩：」我数学142分，怎么刷的？」
- 反常识断言：」努力没用？方法对了才有用」
- 制造损失厌恶：」没时间做完1000题？直接背这份」
- 承诺收益：」一个方法通过任何考试」
- 结论：开头 3 秒 = **结果承诺 / 反常识 / 痛点直击**三选一，不做铺垫

## 三、教育类视频制作规律总结

### 选题
1. 追**刚需痛点**（1000题刷不完/学了就忘/效率低）→ 给解法
2. 蹭**热门身份**（名校/名师/高分）做信任背书
3. 踩**流量词**（学习方法/高效/避坑/干货）

### 制作
| 维度 | 规律 |
|---|---|
| 时长 | 3-7 分钟快干货 或 20-45 分钟深度；带背类可长（1h+） |
| 标题 | 数字 + 悬念/干货 + 身份背书 + 情绪词 |
| 封面 | 大字标题 + 关键数字（142/1000/100倍） |
| 画面 | 文字卡片/录屏为主流；真人出镜加分 |
| 开头 | 3 秒内给结果/反常识/痛点 |
| 结构 | 痛点 → 方法 → 案例 → 总结（快干货）；深度类加理论框架 |

### 结合产品（考研智复习 AI刷题助手）的选题建议
1. 「AI按你学校专业出题？考研刷题新玩法」（工具演示 + 效率反差）
2. 「错题五段分析：考点/错因/解析/避坑/同类」（干货教学 + 产品植入）
3. 「考研刷题 vs AI刷题，30天实测」（对比 + 结果导向，对标142分视频）
4. 时长建议：3-7 分钟演示干货 / 20 分钟深度评测
5. 开头：」考研刷题刷到怀疑人生？AI 按你专业出题后…」
