## 四、配音文案（口语化全文）

刷题别再刷通用题册了——你报考的学校和专业，AI 能直接帮你出题。考研智复习，把刷题从碰运气变成精准打击。

考研人刷题最崩溃的三个瞬间：第一，题册买三本，做完发现一半题跟你专业没关系；第二，错题抄满一本，复习时不知道从哪看起；第三，今天刷完明天就忘，没人告诉你什么时候该复习哪道。如果你也这样，这个 AI 插件值得看完。

打开插件，先填你的报考学校和专业。AI 就按你的目标生成对应章节的练习题，数学一、英语二、政治、专业课都能定向出。难度自己调，想练基础还是冲刺都行。模拟考试一键生成，倒计时自动判卷，跟真考一样。

做错的题自动进错题本，数学英语政治专业课分开归纳，不用自己整理。每道错题 AI 给你五段分析：考点、错因、解析、避坑、同类题。看懂这五段，比抄十遍错题都管用。

复习节奏 AI 也帮你安排：艾宾浩斯遗忘曲线算好每道题的复习紧迫度，到点提醒该刷哪道。还有隐藏玩法：网页看到好资料，右键一键收藏进本地知识库，AI 出题优先从你的资料里出。所有数据存浏览器本地，API Key 不外传。

刷题量少了，但模考正确率涨了——三周实测的感受。不是让你少刷，是让每道题都刷到点子上。评论区聊聊你刷题踩过的坑，或搜"考研智复习"体验一下。下期讲错题五段分析怎么用，下期见。

## 视频流水线参数化（抖音推文）2026-09-07

抖音推文视频 = **确定性参数化流水线**：不写一次性脚本、不靠 agent loop，新书只加一份配置、不改脚本。

### 新书流程（4 步）
1. 写配置：新建 `scripts/pipelines/configs/<slug>.json`（复制现有 weiren/fengqing 配置改字段）
2. 跑流水线：`python3 scripts/pipelines/douyin_video.py configs/<slug>.json`（不带参数默认跑 weiren；解析兜底：显式路径 → cwd/configs/<名> → 脚本目录/configs/<名>）
3. `archive_media`：归档产物 `data/videos/douyin_<slug>.mp4` + `douyin_<slug>_cover.png`（多书并存互不覆盖）
4. `write_draft`：出视频草稿

### 配置字段（scripts/pipelines/configs/<slug>.json）
| 字段 | 含义 |
|---|---|
| book_name | 书名（文字卡角标） |
| alias | 番茄搜索别名（CTA「搜索 alias」/ 页脚） |
| output_slug | 输出文件标识（决定 douyin_<slug>.mp4 命名） |
| segs | 口播+字幕分段 `[[口播文案, 大字幕] × 5 段]` |
