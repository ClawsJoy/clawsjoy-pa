## 一、选书策略

## 三、别名申请（已实测完整流程）

### 3.1 操作流程
```
内容库 → 点书籍行末「别名推广」→ 弹窗打开
→ 填「申请别名」(4-6 字)
→ 选「发文类型」(10 选 1)
→ 点「提交」→ 人工审核(8:00-22:00)
→ 审核通过 + APP 可搜出 → 才能发布
```

### 3.2 发文类型（10 种，实测）
真人出镜 / 图文 / 解压TTS / **解说混剪** / meme剪辑 / **AIGC** / 营销号 / 沙雕漫 / **AI数字人** / 滚屏素材

### 3.3 别名规则（实测）
- **4-6 字**（过多用户记不住）
- 不可涉黄/政/蹭热点/用已有剧名角色名/加符号字母空格
- 上限 10 个（生效+审核中）
- 审核通过 + 自行 APP 搜索可搜出 → 才可发作品

### 3.4 弹窗选择器（实测）
- 入口：`text=别名推广 >> nth=N`（每行一个）
- 弹窗字段：任务类型 / 书籍信息（书名+BookID）/ 申请别名输入框 / 发文类型下拉 / 取消 / 提交

## 四、内容制作（结合视频 SOP）

### 4.1 推荐形式（番茄推广主流）
1. **解说混剪**：素材片段 + 配音解说（悬念/反转叙事）——最高转化
2. **图文推文**：书封面 + 文案钩子（低成本快发）
3. **AIGC/AI 数字人**：AI 生成画面 + 数字人口播（量产）

### 4.2 视频制作流程（复用平台视频 SOP）
```
脚本(钩子3秒+结构) → edge-tts 配音 → PIL 画面卡 → ffmpeg 合成
→ 抖音竖版 9:16 (1080x1920) 适配
```

### 4.3 内容规范（番茄规则相关）
- 视频/评论/合集中挂别名引流（**推荐合集**，其他易被打压）
- 播放量回填单位"万"（1万=1）

## 五、发布 + 回填（7 天闭环）

### 5.1 发布（抖音）
- 抖音创作者中心 → 发布视频（mp4，9:16）→ 视频中/评论区/合集挂别名
- 推荐抖音+快手双平台分发

### 5.2 回填（关键）
```
番茄达人中心 → 推广计划页 → 回填发文（视频链接+播放量）
结算截止 = 发文日期 + 7 天；超 7 天未回填 → 别名自动失效
```

### 5.3 收益
- cpa：新用户搜索别名 → 10.5 元/新用户（活动 10.5-12 元）
- 达人中心自行提现

## 九、番茄推广引导规范（2026-08-26 固化）

### 9.1 挂载位置（评论区/视频/合集）
- **评论区**：每条发布作品的评论区置顶/前排挂引导语「搜『叼着奶瓶杀翻全场』」
- **视频**：口播 + 视频封面 + 视频内文字卡挂别名引导语
- **合集**：**推荐合集引流**（官方明确：合集引流最有效，其他方式易被打压）

### 9.2 禁止事项
- ❌ **不挂外部链接**（官方推荐合集引流；挂外链/其他方式易被打压甚至违规）
- ❌ 不直接放书名/作者名引流（用户搜**别名**才计入你的收益）

### 9.3 文案统一收尾
- 所有推广文案（图文/视频口播/评论）**结尾统一加**：
  ```
  👉 搜「叼着奶瓶杀翻全场」，直接开看！
  ```
- 别名必须与申请一致（当前：**叼着奶瓶杀翻全场**，生效中至 2027-02-22）

### 9.4 引流链路
```
发布作品（抖音/快手，视频或图文）
→ 封面/文案/评论区挂别名引导语
→ 用户搜别名 → 打开对应书 → 新用户计入你的收益（cpa 10.5元/新用户）
→ 7 天内回填发文（播放量单位"万"）
```
