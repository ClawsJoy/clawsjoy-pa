# PA 全新定义与技术栈可行性 v2（2026-10-30）

## 已定

- **PA = 产品壳 + DSH 运行时 + 本地模型 + 权限/审批 + 记忆/证据/编排。**
- 用户要的是“事办成”，不是“模型回话”。
- PA+DSH 大于 1 的来源：记忆、控制、责任、连续、本地、编排。
- 若 PA 只转发 DSH ⇒ =1；若 PA 增加摩擦 ⇒ <1。
- 本地 7B qwen：简单聊天可行，多步工具不可靠；复杂任务需 DSH/云。
- 现有 `core/pa/harness`（Port + DshHarness + store）可用，但**未接进聊天主路径**。
- 正确路线：PA 管状态与责任，DSH 管执行；单主/WIP=1 保留，异步做“对话不阻塞 + 执行排队”。
