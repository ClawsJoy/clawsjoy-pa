# 产品路线总览与可行性（2026-10-30）

## 一、已落地

- 第二大脑 note：Markdown/YAML、FTS、导入 MD、语音笔记；
- 内置浏览器：读页、存脑、关闭页、target=_blank 同页打开、视频全屏权限；
- 屏幕录播：悬浮控制条、麦克风/系统音频、ffmpeg 时长修复、30 分钟上限；
- 视频字幕：当前视频、页面字幕、AudioContext 音轨、5 秒轮询、时间线；
- 本地模型：Ollama qwen2.5 7B 默认；
- 能力自述：能力事实对象 + 本地 qwen 自然表达（本轮新落地）。

## 二、半成品

- 通用导入：只支持 MD；PDF/图片/音视频未接；
- ASR：准实时，不是逐字流；
- 插件/技能：无运行时，无市场；
- 工作流沉淀：无统一对象；
- 任务执行台：散在 Agent/台账/事件；
- 画像：字段与接口在，但文件为空时显示“未建立”未统一；
- v9_chat：仍硬绑 DeepSeek key。

## 三、可行性分级

### P0（1-2 周，低风险）

1. 能力事实/表达分离（本轮已做第一步）；
2. 本地默认生成 + 缺 key 回退本地；
3. 画像空态文案修正；
4. 首启 3 个示例任务；
5. 流式会话（首 token 优先）。

### P1（1-2 月，中风险）

1. 通用导入：TXT/PDF/图片 OCR/音视频；
2. 批量队列、去重、进度；
3. MCP 插件客户端 + manifest + 权限门；
4. 任务控制台：步骤/暂停/停止/回执；
5. 工作流候选/确认/复用。

### P2（季度，高风险）

1. DSH 通用 Agent 适配器；
2. 插件市场索引与签名；
3. 手机相册/局域网导入；
4. DSH 兼容层（子集）；
5. 多 Agent 席位。

### P3（长期）

1. 链上批量记账；
2. 摄像头/传感器；
3. 设备生态；
4. 真 OV/EV 签名。

## 四、可行性判断

- 数据层最强：已有基础，主要补格式与队列；
- 执行层中等：事件/台账有，缺统一任务对象与授权卡；
- 表达层最弱：自述拦截、整段返回、Key 错误；
- 插件层最难：安全、权限、兼容、生态；
- DSH 内置可行但建议 P2，先做 MCP。
