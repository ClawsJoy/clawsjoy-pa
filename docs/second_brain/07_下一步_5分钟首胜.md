# 下一步：5 分钟首个结果（P0）

> 2026-10-29 · 第一大脑文档 ｜ 从“功能很多”转向“产品被证明”

## 0 一句话

**下一步不是 9.0.17，而是让一个新用户在不装 Obsidian 的情况下，5 分钟内从本地笔记得到一个带出处、可执行的结果。**

## 1 目标

~~~text
装 PA
 → 选一个本地文件夹/笔记目录
 → 本地模型自检
 → 问：“我这周记了什么？哪些没做完？”
 → 带出处回答
 → 生成待办
 → 人批写回
 → 回执
~~~

## 2 为什么是这一步

- 当前 9.0.16 有壳、有发送、有停/回执，但**第二大脑还没真正可用**；
- 用户装完 Today 全 0，没有“非它不可”的瞬间；
- Web3/设备/摄像头都建立在“用户先留下”之上；
- 这一步不通过，后面都是演示。

## 3 P0 工作流

1. **Note core**：Markdown 文件＋SQLite FTS；索引可重建；
2. **Capture**：Today 快速记、Summon “记：…”、热键；
3. **List/Search**：标题/正文/标签；
4. **Import**：选一个本地目录，导入 md（Obsidian 可选）；
5. **Ask**：检索→本地模型→带 note id 出处；
6. **Task extraction**：从回答生成待办；
7. **Write-back**：人批→写 note→快照；
8. **First-run**：选目录/模型自检/一条示例；
9. **Receipt/Stop**：可停、可查。

## 4 两周节奏

- 第 1–2 天：冻结 note schema、索引、数据落点；
- 第 3–5 天：note 编辑/列表/搜索/快速记；
- 第 6–8 天：导入 md 目录、带出处问答；
- 第 9–10 天：待办提取、人批写回、首跑向导；
- 第 11–14 天：10 个真实用户，7 天。

## 5 验收标准

- 全新安装、**不装 Obsidian**，5 分钟内拿到首个带出处答案；
- 至少 3 条引用可点回原文；
- 至少生成 3 条待办并可写回；
- 写回可撤销；
- 10 个用户中 ≥6 个第 7 天还在用；
- 10 个金标任务成功率 ≥70%。

## 6 现在不做

- 不发币；
- 不先做链上记账；
- 不先做摄像头/全屋设备；
- 不先做多厂 Agent 市场；
- 不追求功能数量；
- 不把自签当公开可信。

## 7 如果失败

- 不是加功能，而是换楔子：
  - 换人群（知识工作者/小老板/创作者）；
  - 换场景（周报/资料问答/会议纪要）；
  - 换交互（录音优先/文件优先）。
- 记录失败证据，不粉饰。
