# 插件与能力层 · 下一步更新计划

> 2026-10-30 · 产品计划 ｜ 承接「插件属于 PA，技能可绑 Agent，Agent 不拥有安装权」

## 一、三层模型

~~~text
用户（PA 页端）
  ├─ 安装/卸载插件
  ├─ 授权权限
  ├─ 启用/停用技能
  └─ 设定默认能力范围

PA（主脑/编排）
  ├─ 发现已启用插件与技能
  ├─ 按任务组装能力包
  ├─ 分派 Agent 时只授予子集
  └─ 需要新插件时向用户申请，⛔ 不自动安装

Agent（席位/执行）
  ├─ 只使用被授予的插件/技能
  ├─ 不能安装、不能越权
  └─ 任务结束即回收
~~~

## 二、插件 vs 技能

| | 插件 Plugin | 技能 Skill |
|---|---|---|
| 本质 | 可执行能力：工具/数据/UI/模型 | 提示词/流程/工作方法 |
| 安装位置 | PA 宿主 | PA 全局，或绑定某个 Agent |
| 权限 | 文件/网络/密钥/shell 逐项授权 | 通常无系统权限 |
| 谁能装 | 用户 | 用户/PA 提议，用户确认 |
| 谁能用 | PA 或 PA 授予的 Agent | PA 或指定 Agent |
| 自动安装 | ⛔ 不能 | ⛔ 不能静默装 |

## 三、插件类型

| 类型 | 例子 | 风险 |
|---|---|---|
| Capability / Tool | 搜索、日历、数据库、MCP server | 中 |
| Data source | 笔记源、邮件、RSS | 高 |
| UI panel | 新页面、侧栏卡片 | 中 |
| Model provider | 新 API/本地模型 | 低 |
| Automation | 定时任务、工作流 | 高 |

## 四、统一插件 manifest

~~~yaml
id: com.example.calendar
name: Calendar
version: 0.1.0
entry: mcp
transport: stdio
command: ["node", "server.js"]
permissions:
  - net:api.example.com
  - fs.read:workspace/calendar
  - secrets:CALENDAR_TOKEN
capabilities:
  - calendar.list
  - calendar.create
min_host_version: 9.1
plugin_api: 1
signature: ...
~~~

## 五、执行与安全

- **MCP-first**：stdio / HTTP MCP server，独立进程；
- 不把插件代码加载进主进程；
- 文件、网络、密钥、shell 逐项授权；
- 默认拒绝，用户显式开启；
- 资源限额、超时、日志、一键停用；
- 安装前显示权限清单；
- 固定版本/commit，不自动跟 main；
- 校验 hash/签名；
- 不执行任意 postinstall。

## 六、安装流程

~~~text
来源（本地/GitHub/市场）
 → manifest 校验
 → hash/签名
 → 权限预览
 → 隔离进程启动
 → 用户启用
~~~

## 七、UX 落点

1. **PA 设置 → 能力**：插件/技能列表、安装、权限、启停；
2. **任务卡 → 本次能力**：显示并允许调整；
3. **Agent 卡 → 工具/技能**：只读展示被授予项；
4. **首次使用 → 权限确认**；
5. **PA 提议安装 → 用户确认**。

## 八、市场索引

不手改市场；CI 生成：

~~~text
扫描仓库 → 校验 manifest/hash → 生成 index.json → 签名 → 发布
~~~

来源：

- 官方签名索引；
- GitHub / 用户自加源；
- 本地插件目录。

## 九、DSH 兼容层

- 不能二进制直接兼容；
- 只做**声明式 UI/命令子集**或独立 host 子进程；
- 显示兼容等级：官方验证/部分兼容/仅声明式/不支持；
- 长期维护成本由我们承担，不承诺永久全兼容。

## 十、MVP 顺序

1. MCP 客户端 + 本地插件目录；
2. plugin.yaml + 权限门 + 启停；
3. GitHub 固定 commit 安装；
4. UI 插件声明式 API；
5. 市场索引；
6. DSH 兼容适配器（最后）。

## 十一、发行门

- payload 不含 data/profile/workspace/notes/attachments/sessions；
- 首启空白；
- 示例必须标【示例】且可清空；
- 不带个人 Obsidian 路径；
- 第三方插件不自动执行。
