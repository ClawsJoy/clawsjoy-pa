# 未来交互：视觉与传感器（v1）

> 2026-10-29 · 第一大脑文档 ｜ 第二大脑：workspace

## 0 一句话

**摄像头是 PA 的眼睛：事件驱动、边缘处理、默认本地；不是 24 小时云录像。**

## 1 自动驾驶类比：学什么，不学什么

学：

- 多传感器融合（摄像头/麦克风/位置）；
- 感知 → 事件 → 世界模型 → 决策；
- 低延迟、边缘推理；
- 失败安全、可回放、数据闭环；
- OTA 升级。

不学：

- 默认全程录制；
- 原始视频上云；
- 黑箱决策无回执；
- 把“感知”当“事实”。

## 2 三种视觉交互

1. **显式采集**
   - 用户举起手机/摄像头：拍一下、录一段、扫一下；
   - 明确开始/停止，有指示灯；
   - 落成 note/任务/引用。

2. **环境记忆（opt-in）**
   - 眼镜/穿戴/固定摄像头；
   - 只在用户开启的时段；
   - 事件切分，不存整段原始流；
   - 默认本地。

3. **实时协助**
   - 修东西、做饭、看屏幕、会议；
   - 低延迟视觉问答；
   - 人类确认后才行动。

## 3 架构

~~~text
摄像头/麦克风/屏幕
  → 边缘采集（本地）
  → 视觉/语音模型（本地优先）
  → 事件切分（人/物/动作/场景）
  → 第一大脑：观察/实体/关系/任务
  → 第二大脑：片段/截图/笔记/时间线
  → 用户问答/行动/回执
~~~

原则：

- 原始视频本地加密；
- 只上传/保存事件片段，默认不上云；
- 每个观察带时间、设备、置信度；
- 可删除、可导出、可关闭；
- 行动须人批。

## 4 数据模型

- sensor_event：设备、时间、类型；
- observation：看到了什么、置信度；
- entity：人/物/地点（本地 ID，不一定是真名）；
- clip：短片段/关键帧；
- note：用户可编辑的工件；
- memory：第一大脑事实。

## 5 隐私与合规

- 录制指示灯/声音提示；
- 旁观者同意；
- 保留期与一键删除；
- 本地加密；
- 不默认上传；
- 不把面部/隐私数据上链；
- 遵守 PIPL/GDPR 等；
- 摄像头被劫持是安全风险，要权限/加密/审计。

## 6 产品价值

- **视觉记忆**：东西放哪、客户说了什么、这个流程怎么做；
- **免手操作**：做饭/维修/开车时；
- **流程 capture**：看一遍就会，转成步骤；
- **无障碍**：视障/老人辅助；
- **本地所有权**：云相机看不到你的家。

## 7 路线

- P0：文本/语音/PDF（现在）；
- P1：手机摄像头显式拍照/短片 → note；
- P2：眼镜/穿戴 opt-in 环境记忆；
- P3：多传感器世界模型 + 行动。

## 8 非目标

- 不做全程监控；
- 不做云端视频池；
- 不默认常开；
- 不无审批执行；
- 不把视频明文上链。
