# 通用导入与自动归档（v1 设计）

> 2026-10-29 · 第一大脑文档 ｜ 从“只导 MD”到“任意资料进第二大脑”

## 0 一句话

**统一入口 → 原件入 Inbox → 类型识别 → 解析器 → Note → 自动分类 → 归档索引。**

## 1 当前实况

| 格式 | 现在 | 目标 |
|---|---|---|
| MD | ✅ 可导目录 | 保留 |
| TXT | ❌ | ✅ 文本 note |
| PDF | ❌ | ✅ 文本/页码；扫描件 OCR |
| JPG/PNG | ❌ | ✅ OCR/描述＋EXIF |
| MP3 | ❌ | ✅ whisper 转写 |
| MP4 | ❌ | ✅ 音轨转写＋关键帧 |
| 手机相册 | ❌ | ✅ 先走导出目录；后续手机上传 |
| 批量/进度/去重 | ❌ | ✅ 队列＋进度＋hash 去重 |
| 自动分类/归档 | ❌ | ✅ 规则先、模型后、可回退 |

## 2 统一流水线

~~~text
选择文件/目录/手机导出目录
  → Inbox（原件＋sha256＋metadata）
  → 类型识别
  → 解析器：
       md/txt  → 文本
       pdf     → 文本＋页码＋OCR
       jpg/png → OCR/描述＋EXIF
       mp3     → whisper
       mp4     → whisper＋关键帧
  → Note（可编辑，带出处/页码/时间码）
  → 自动分类（类型/日期/来源/项目；模型补标签）
  → 归档（复制，不移动原件）
  → 第一大脑索引
~~~

## 3 数据模型

~~~text
source_document:
  id, original_path, sha256, mime, bytes,
  imported_at, source, status, parser, error
note:
  id, title, body, tags, provenance
attachment:
  original, preview, keyframes, audio
~~~

- 原件保留；
- 每件有 hash，重复导入跳过；
- 解析失败明说，不假装有内容；
- 不自动删除源文件。

## 4 批量导入

- 选多个文件/整个目录；
- 队列串行或限并发；
- 每件状态：待处理/解析中/完成/失败；
- 进度条、暂停、取消；
- 失败可重试；
- 大文件/大目录有上限；
- 导入后给汇总：成功/跳过/失败。

## 5 自动分类与归档

- 规则优先：扩展名、EXIF 日期、目录名、文件名；
- 模型补标签：主题/项目/人物（带置信度）；
- 不静默移动原件；
- 归档到 workspace：
  - 按日期/来源/类型/项目；
- 用户可改标签/目录；
- 分类不可靠时标“未分类”，不硬猜。

## 6 手机相册

P0：手机导出目录/网盘同步目录，PA 选目录批量导入；
P1：手机扫码上传到本机 PA（局域网，不出公网）；
P2：相册增量同步、去重、地理/时间线。

先不做 MTP 直连（Windows 兼容差）。

## 7 解析依赖

- PDF：PyMuPDF/pypdf；
- OCR：Tesseract/PaddleOCR（按语言）；
- 图片：Pillow＋EXIF；
- 音频/视频：faster-whisper（已有）＋PyAV/ffmpeg；
- 视频关键帧：PyAV（已有）；
- 文本：md/txt 原生。

## 8 MVP 顺序

1. 通用文件/目录选择＋拖入；
2. MD/TXT 文本导入；
3. PDF 文本＋页码（扫描件先 OCR 占位）；
4. JPG/PNG OCR；
5. MP3/MP4 whisper＋关键帧；
6. 批量队列/进度/去重；
7. 规则分类＋归档；
8. 手机导出目录；
9. 手机扫码上传。

## 9 风险

- 存储爆炸（视频/照片）；
- OCR/转写质量；
- 重复导入；
- 隐私（相册/合同）；
- 解析阻塞 UI；
- 自动分类误判；
- 手机格式/HEIC。

## 10 原则

- 原件永不留失；
- 复制不移动；
- 解析失败可见；
- 分类可改；
- 默认本地；
- 不把资料明文上链。
