# 内置浏览器（Agent Browser）v1

> 2026-10-29 · 第一大脑文档 ｜ 类似 Paseo 的内嵌浏览器，但先安全、再自动化

## 0 一句话

**可以内置：Electron WebContentsView ＋ 独立 session；但 Agent 只能通过主进程白名单工具读/动网页，不能拿到 Node。**

## 1 为什么值得做

- 用户不用切浏览器，PA 就是 AI 入口；
- Agent 能看当前页、抓正文、截图、填表、点按钮；
- 网页内容可直接进第二大脑（带 URL/时间/选中文本）；
- 登录态留在本机，云端看不到；
- 与“管各厂 Agent／管设备”同一入口。

## 2 架构

~~~text
主窗口
  └─ WebContentsView（内嵌 Chromium）
       session: persist:pa-web（独立 profile）
       nodeIntegration=false
       contextIsolation=true
       sandbox=true
       webSecurity=true

主进程（唯一特权）
  ├─ 导航/标签/权限/下载/证书
  ├─ CDP/Playwright 桥（只对 pa-web）
  └─ Agent 工具白名单：
       browser_open / read / snapshot / click / type / screenshot
~~~

- 渲染层只拿“页面快照/操作结果”，不拿 CDP 原始句柄；
- 外部链接默认走系统浏览器；
- file:// 禁止；下载需确认；权限（摄像头/麦克风/定位）默认拒绝。

## 3 安全红线

1. 远程页面**不得**访问本地文件/Node/主进程；
2. 独立 persist:pa-web，与 app 会话隔离；
3. 禁止自动读取 cookie/密码/令牌；
4. 登录由用户手动完成；Agent 不代填密码；
5. 点击/输入/购买/发帖属 L2/L3，须人批；
6. 截图/正文可进第二大脑；密钥/密码字段不入日志；
7. 退出/清档可一键清 session；
8. 任何页面脚本不能直接调 PA 工具。

## 4 能力分级

- **P0 读**：打开 URL、读正文、截图、抓选中文本、存 note；
- **P1 动**：点击、输入、滚动、下载（逐次批）；
- **P2 自动**：多步任务、表单、登录后操作（强审批）；
- **P3 高风险**：支付、发布、删除、账号安全设置（默认不做）。

## 5 MVP

1. 内嵌浏览器 tab＋地址栏/前进后退/刷新；
2. 用户手动登录，session 持久；
3. Agent 读当前页正文/标题/URL；
4. 截图/选中文本 → 第二大脑 note；
5. 点击/输入先只做“提议”，人点才执行；
6. 权限/下载/外链统一门禁。

## 6 和 Paseo 的差别

- Paseo 类产品证明“内嵌浏览器＋Agent”可行；
- PA 的差异：**本地优先、独立 profile、门禁/回执、网页内容进自己的第二大脑**；
- 不追求第一版就全自动浏览。

## 7 非目标

- 不做通用浏览器替代；
- 不默认保存密码；
- 不让 Agent 无审批支付/发帖；
- 不把浏览历史/页面明文上云或上链；
- 不先做多账号/多窗口。

## 8 排期

- 现在：P0 第二大脑（note/问答）；
- 下一步：内置浏览器 P0（读＋截图＋存 note）；
- 再下一步：P1 点击/输入；
- 设备/摄像头仍后置。
