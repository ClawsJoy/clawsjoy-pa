## 一、层位（第一道筛：答不出补哪一层 ⇒ 不做）

| 问 | 不合格 | 合格 |
|---|---|---|
| 它补哪一层？ | 「更智能」 | 可指认的层位（例：补 L3 控制面的投递前闸） |

**第一道筛（不是门）**：三条全过才进入评审；**过了筛不等于入册**（入册门见 §六）。

## 二、模块形态（ToolPlugin 契约）

1. **单一职责**：一个模块只补一个层位。
2. **形态**：`name` + `schema`（模型可见）+ `execute(args, ctx)`；返回 `{success, level, data|error}`。
3. **分级**：每动作显式声明 `read` / `write` / `destructive`；破坏性动作走**在场授权**（归属见 §五 `pa.authority`）。
4. **无隐式全局**：状态落 ctx 作用域，或显式声明为进程级单例并写明理由。
5. **不猜路径**：落点由调用方给定或由锚定 base 派生；禁止依赖裸相对路径。
6. **入口唯一**：不得绕过治理门直连外部服务。

7. **五件套（v1.3 · 并入 DSH `a18a4ee3` 的四件套 + DS 裁的第五件）**：**声明 / 实现 / 判据 / 回退 / 成本·配额**。第五件 = **成本**（单位 + 量法）+ **判据**（超限行为：拒 · 降级 · 报警）+ **回退**（超限后走哪条路）。**只引用不复述**：正文与判据留在来源件与各模块自己的复算器（`L-09`）。来源 = `开发区\架构与路线图\V9PA_可复用能力插件化设计标准_v0.1_20260919.md`（**已被本件取代，保留作历史引用**；被 DS 裁定的那一版 = `a18a4ee3`，盘上现行见 §十二）。**门槛句（v1.6 并入 · DSH 差异清单 #1）**：**缺 `判据` / `回退` 键 ⇒ 该能力不得登记为「插件」，只能标「脚本」**（正问）；**它该红的那一格（v1.7 补成两格 —— 正问管两个键，就配两个红格）**：① 造一张缺 `judge` 的卡 ⇒ **落册门必须拒**；② 造一张缺 `rollback` 的卡 ⇒ **落册门必须拒**（现状**两格都会放行 ⇒ 两格现在都是红的**；`L-55`：规则 → 判据才算了结）。⚠ **尺尚未造**（DSH 第 4 轮初审 ①：文字落了、判据没落）⇒ 已登记 §五.2 解除条件。

## 三、六条硬标准（每条附「该红的那一格」）

### S1 单一真源，**且不复述数值**
- **要求**：判据与被判方共用同一函数；**目标阈值 / 端口 / 窗口常量一律只引用、不复述**（引件 + sha）。
- **该红的那一格**：改唯一函数 ⇒ 负对照立刻红；**复述了常量 ⇒ 常量一变，标准自己漂**（这一条对本件同样适用）。
- **真实历史实例（v1.2 补 · 改前件在盘可复算）**：
  - ① `dsh_wake.ps1` 的批号上限原写在**调用者口径**里 ⇒ 抽成 `-Ledger`，规则只有一份；**改前件** = `data\tmp\kb_insert\fixtures\w4_gate_old_before_0511629d.ps1`（10,792 B，在盘）；现行 `dsh_wake.ps1` = `142aa2c8`。
  - ② `post_ds.mjs` 原**自带一行**消费确认判据 ⇒ 抽到 `post_ds_ack.mjs`（`bb2f3079`），由**被判方与判据方共用同一函数**（同源，不是复制一份来测）。
- 常量的家（**不复述数值**）：抓取窗口见 `data\tmp\tools\chan_readgap_probe.py` 的 `SNIP_CAP`；Windows 副本端口见 `config\v9\execution_policy.yaml` 的 `browser_local.ws_port` 与 `config\system\system_unified.yaml` 的 `services.gateway.port`；探针时效见 `mcp_bridge_probe.py` 的 `MAX_AGE_MIN`。

### S2 判据必须能红
- **要求**：每条判据配负对照；负对照本身还要有一条「换个坏口径必红」的对照（**对照的对照**）。
- **坏口径必须取自真实历史**（改前件那一版），不得自编一个必错函数。
- **该红的那一格**：关掉该校验 ⇒ 同输入被放行。
- **机锚（v1.3）**：`data\tmp\tools\selftest_want_scan.py`（`00243ca6`）—— 取各复算器 `--selftest` 的**判决码集合**，断言「**至少有一个非 0 判决码**」；只有正对照的件 ⇒ `GREEN_ONLY` ⇒ 红（自测：删掉负对照立刻红；`--legacy-14` 复现 v1 的假红）。**判据不复述词表**：词表由各件 `--selftest` 自己给出（v1 写死 `1/4` ⇒ 对 `mcp_bridge_probe` 假红，见 §〇.2 自踩②）。

### S3 三态退出码，`INCONCLUSIVE` 不被吞
- **要求**：`0`=过 · `1`=红 · `4`=前提不成立（不猜、不判过）。`4` 一律 fail-closed：判定须在「全绿」汇总**之前** `exit`。
- **该红的那一格**：静默段（无变化、无丢弃）必须落 `4`，不得写成 `0`。

### S4 出站闸（写出去之前先看对面）
- **四条**：① 投前扫**收件人交付面** ② 同 sha 幂等 ③ 批号上限（append-only 台账不得出现单向棘轮）④ 在飞不重发。
- **起身判据在收件人侧**（交付面 + 状态时间戳），不是「我发了」；过程日志只作过程。

### S5 消费确认分两条径
- **写径**：消费确认 = 队列项消失。**读径**：读全 = 拿到的字节等于全文。

### S6 资源面单源（端口 / 宿主 / 路径 / 代理）
- **一个环境一个入口**：端口、宿主、路径各只有一个出口常量，其他调用点调它。
- **loopback 不得走代理**（否则本机调用被劫持，报错长成「远端断连」这种误导形状）。
- **机读条件（替代歧义词「错峰」）**：同名服务在两副本上的端口**不相等**；且本副本的该端口 `LISTEN` 应归属本副本 pid。
- **Windows 副本证据写成两半**：① Windows 侧该端口**无 `LISTEN`**；② 对端存在**指向它的 `ESTABLISHED`**（作为旁证，比单说「不可绑」更可比对）。
- **该红的那一格**：改端口只改一处 ⇒ 另一处因单源跟着变；不变 ⇒ 单源没做到。**正对照**：同刻另一个候选端口必须**绑得成功**（证明失败是端口特异，不是环境全线不可绑）。

## 六、入册流程与**落册门**（正式门只有这一份）

`提案（带 §一 三答 + 自检）` → `初审 DSH-windows` → `修复` → `复审 DS` → `落册`（两道不并发）。

### 入场券（§一 三答，**不是门**）
过券只代表「值得花评审时间」；**过券 ≠ 入册**。

### 落册门（唯一正式门）

**模块类提案** —— 必须交**四元组**（每条判据一条）：

| 元 | 含义 |
|---|---|
| 命令 | 能跑起来的复算器调用 |
| 期望 rc | 正常输入下应有的码 |
| 该红输入 | 坏口径 / 篡改 / 静默段等 |
| 该红输入下的 rc | 期望的 `1` 或 `4` |

⇒ **由入册方亲手跑这四条**（提案方附读数**不算**，`L-70`：正对照不得依赖被验证者自身状态）。

**另必答一栏（v1.2 新增 · 由 §五.1 推出）**：**该能力走的是哪一套授权** ——

| 情形 | 必答 |
|---|---|
| 走 PES 对象级授权 | 给**调用点**（文件 + 行号），且须在**生产路径**上（仅测试命中 ⇒ 不算） |
| 走老场景级门（`core\pa\grants.py`） | 写明**理由**与**归一计划**（何时并入 `decide()`） |
| 两套都不走 | **不入册** |

**注册面接线两条件（v1.3 新增 · DSH 二轮条件①②；不满足 ⇒ 「已归一」不许写）**：

| # | 条件 | 判据（可复算） |
|---|---|---|
| ① | **是接线，不是改口径** | 给出**调用点（文件 + 行号）且在生成路径上**；「仅测试命中」不算。现网读数：`from core.pes` 共 23 处、**无一处**导入 `authorization`；`core\pa\gateway_routes.py:592` 那个 `Authorization` 是 **HTTP 头**，不是授权模块 |
| ② | **只读 / 投影路径不得触发写** | 现网反例：`core\pa\pes_projection.py:143` 明写「本模块不调 `Authorizer.explain()` —— 那会 `ensure_seeded()` **写注册表**（违反 P3）」⇒ 归一必须先定义「只读路径不写注册表」（如 `explain(readonly=True)`），否则归一会引入新的 P3 违规 |


**标准类提案** ——（**v1.1 新增，补的是 v1.0 的自指缺口**）：

1. 每条标准有一个「该红格」的**真实历史实例**（给出改前件 sha）；
2. 每条引用**带 sha**；
3. 标准自身的每条断言**能被既有复算器验**（不要求标准自带复算器，但要求「可被已有尺量」）；
4. **不得复述目标阈值 / 端口常量**（一律改指针 —— 否则标准会随常量漂）。
5. **§八 不得含 `rc` 要求**；「该红输入下的 rc」只许出现在本节（**结构锚** · 替代不可直接跑的裸字符串检索 ⇒ DSH 二轮 #3）。

### 判据模板（**骨架 · 非契约** · v1.6 并入 · DSH 差异清单 #2）

⚠️ **防撞 §十 第 3 条「自指留一格」**（**按节号名引，不按本件行号引** —— 行号自指会随换版漂）：

| 栏 | 写什么 | 不写 ⇒ 该红的那一格 |
|---|---|---|
| 能力 / 入口 | 能力名 + **入口那一格**（函数 / 路由 / 命令） | 只写能力名 ⇒ 被测面无法定位 |
| 载体 | **读数载体**：DOM / API · 夹具 / 生产 · decoded / wire（对应 §三.1 载体声明） | 不写 ⇒ 读数无法归因 |
| 鉴权 | 走 PES 对象级 / 老场景级门 / 都不走（§六 必答栏） | 不写 ⇒ 撞必答栏 ⇒ 不入册 |
| 正对照 | 命令 + **期望 rc = 0** | 只有正对照 ⇒ §七 第 8 条（恒绿读数被当证据） |
| **负对照** | 坏口径输入 + **期望 rc = 1** | 没有它 ⇒ 不知道判据会不会红（**S2**） |
| **空转对照** | 「什么都没发生」那一格 + 期望（**0 或 4**，不许混） | 没有它 ⇒ 把「没跑」读成「跑过且对」（`L-67` 同族） |
| 回退 | 失败 / 超限后走哪条路（+ 该路是否被测过） | 不写 ⇒ 五件套缺一件（§二 第 7 条门槛句） |
| 前提不成立 | 输入缺失 / 载体不可读 ⇒ **rc = 4**，**不许判过** | 用 0 兜底 ⇒ `INCONCLUSIVE` 被吞（**S3**） |
**互链**：**S2**（判据必须能红）＋ 每条负对照另配一条「**换个坏口径必红**」的判据（`L-68`）⇒ 模板本身**不得变成孤立规则**。

## 七、反模式清单

**上位条（v1.1 新增）：自述必须可复算。** 任何「我做了 X」都必须能被盘上事实复算；不可复算的自述 = 无效自述。（第 2、3 条挂其下，**不合并** —— 修法不同。）**可核形式（v1.3 · DSH 二轮 #5）**：第 2、3 条**各配一个不同命令的四元组**（命令不同 · 该红输入不同）⇒ 「不共用」才可核。

| # | 反模式 | 要点 |
|---|---|---|
| 1 | 门假设未证 | 正文见 §一（**此处不重复**） |
| 2 | 申报不实 | 没跑就说没跑、跑了就说跑了；边界句必须照实况写 |
| 3 | 指纹面撒谎 | 主体改而伴生未同批重生成 ⇒ 按伴生对账会拿到盘上不存在的旧 sha |
| 4 | **代理阈值 ≠ 目标阈值** | 读数的量程与判据的阈值不是一回事（例：尾窗当阈值） |
| 5 | `--dry-run` ≠ 零写入 | dry-run 也可能落盘；语义必须写进件头与 `--help` |
| 6 | 尺寸相同 ≠ 未变 | 同尺寸改写只有内容指纹能抓；四元组 = 名称 + 字节 + mtime + 指纹 |
| 7 | 把「没落盘」当成「没投」 | 投递面不由数据目录派生；隔离数据面 ≠ 隔离投递面 |
| 8 | **恒绿读数被当证据** | 判据**结构上不可能红** ⇒ S2 的反面实例。**可跑断言（v1.3 机化）**：`selftest_want_scan.py` ⇒ 判决码集合必须含**非 0** 码；只有正对照 ⇒ `GREEN_ONLY` ⇒ 红。⚠ **本条原来正是它点名的病**（DSH 二轮 🔴#6：它只是「先问」的规则）—— 规则 → 判据才算了结 |
