# PA 桌面窗与信任设计 v1

> 呈：老板｜作：DSH（老板 PA）｜2026-10-27
> 依据：`v9_pa_project_proposal_v1.md`（定义／入口／六层）＋ 老板本轮两问（桌面窗怎么设计；信任如何建立，而不是多一道门）。

---

## 0 一句

**窗是仪表盘，不是功能目录；信任是可核的账，不是多一道门。**

门只在风险处出现；低风险时它应当**看不见**。

---

## 1 Strata：借什么，不借什么

你提 Strata，我理解你借的是它的**功能性与精准**：一屏、少装饰、键盘优先、本地优先、状态清楚、动作可达。

| 借 | 不借 |
|---|---|
| 仪表盘的克制：一屏、准、快、少层级 | 它仍是「一个工作台」；PA 是「一位主人的总管」 |
| 本地优先、模型可换、API 兼容 | 它面向「操作」；PA 面向「意图」 |
| 键盘优先、命令可达 | 它单 agent；PA 多 agent（本机席／CLI／云 API／云 VM） |
| 状态与读数清楚 | 它没有主权面（保险库／账本／门） |

⇒ **PA 的窗不是 Strata 的窗**；借它的「仪器感」，不借它的「工作台形」。

## 2 桌面窗：四个形态

### 2.1 Summon（召之即来）

- 全局热键唤出，屏幕上方居中，约 520 × 84；
- 一个输入框 ＋ 三个状态芯片：**陪伴／办事／审计**；
- 最近一件事、最近一个 agent、最近一笔账；
- Enter 发；Esc 收；拖文件进来即带上下文。

### 2.2 Today（默认主窗）

- 约 1120 × 760；左 64px 窄栏，中 Today，右 320px Now；
- 打开即 Today；⛔ 打开即聊天。

### 2.3 Focus（一件事在跑）

- 中栏变任务卡：计划步骤、当前步、进度、花费、可否停；
- 右栏变「待你批」＋「将出机」；
- 完成后回 Today，落一张回执卡。

### 2.4 Audit（查账）

- 全宽时间线；筛选：人／agent／风险／出机／成本；
- 每条可展开：做了什么／凭什么／动了什么／花了多少／可否退／前一条哈希。

## 3 主窗布局

```
┌──────────────────────────────────────────────────────────────┐
│  ● 老板 · 本机      [ 陪伴 | 办事 | 审计 ]     本地·未出机   ■ 停 │
├────┬───────────────────────────────────────┬─────────────────┤
│ 今 │  今天                                  │  在跑            │
│ 席 │  ┌──────────┐ ┌──────────┐            │  · ②v1 拆件      │
│ 账 │  │ 该办 3   │ │ 在等 2   │            │    32%  ¥0.00  ■ │
│ 库 │  └──────────┘ └──────────┘            │  · ④ 分类        │
│ 门 │  ┌──────────┐ ┌──────────┐            │    等 PM         │
│    │  │ 在跑 1   │ │ 要拍 1   │            │                 │
│    │  └──────────┘ └──────────┘            │  待你批          │
│    │                                       │  · 云 VM 起一台  │
│    │  ┌─────────────────────────────────┐   │    出机：方案    │
│    │  │ 说一句话，或拖一件东西进来…      │   │    [看] [批] [否]│
│    │  └─────────────────────────────────┘   │                 │
│    │                                       │  将出机          │
│    │                                       │  · 0 项          │
├────┴───────────────────────────────────────┴─────────────────┤
│  Ctrl+Shift+Space 唤出 · Ctrl+. 停 · Ctrl+K 命令 · Esc 收     │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 顶部状态带（一行说清）

- 左：主人 ＋ 本机；
- 中：**陪伴／办事／审计** 三态（一眼可辨、一键可换）；
- 右：**本地·未出机** 或 **将出机 N 项**；**■ 停**。

### 3.2 Today 四卡（只四件）

1. **该办**：今天要办，人话，最多 3 件；
2. **在等**：谁在等你（人／agent／审批）；
3. **在跑**：正在跑的活，进度／花费／停；
4. **要拍**：需要你决定的，一件一件，带默认建议。

### 3.3 命令带（唯一输入）

- 一句话即发；
- 三个前缀可选：`/陪` 只商量、`/办` 真动手、`/查` 查账；
- 拖文件／截图／选中文本进来即上下文；
- 发前若涉出机，先显「出什么／给谁／为什么／多久删」一行。

### 3.4 右栏 Now（三块）

| 块 | 内容 | 动作 |
|---|---|---|
| **在跑** | 任务、步骤、进度、花费 | 停 ／ 看 ／ 催 |
| **待你批** | 风险、方案、出机、预算 | 批 ／ 改 ／ 否 |
| **将出机** | 数据级别、去向、期限 | 看明细 ／ 改 ／ 否 |

### 3.5 五个面（左栏图标，键盘可达）

| 面 | 一句话 | v1 范围 |
|---|---|---|
| Today | 我现在该知道什么 | 全 |
| Agents | 谁能干、在干什么、花多少 | 只读 ＋ 停 |
| Ledger | 发生了什么、可否退 | 只读 ＋ 导出 |
| Vault | 什么是私密的、出没出机 | 只读 ＋ 导出 |
| Doors | 什么允许、什么要问、什么禁止 | 只读 ＋ 一次一码 |

⚠ v1 **不新做五个大页面**；先把 Today ＋ 命令带 ＋ Now 做实，其余四面只读投影。

### 3.6 快捷键

| 键 | 动作 |
|---|---|
| `Ctrl+Shift+Space` | 召出／收起 Summon |
| `Enter` ／ `Shift+Enter` | 发 ／ 换行 |
| `Ctrl+.` | 停当前任务 |
| `Ctrl+K` | 命令面板（跳面／找人／找账） |
| `Esc` | 收 Summon ／ 退 Focus |
| `Ctrl+Z` | 可退则退（带确认） |

### 3.7 五态（都要设计）

1. **空**：第一次，五步引导；
2. **跑**：步骤，不是转圈；
3. **等**：等谁、等多久、可否催；
4. **错**：人话 ＋ 因 ＋ 下一手 ＋ 可否退；
5. **离线**：本机能力可用；云侧标灰，⛔ 假可用。

### 3.8 首跑五步（≤5 分钟）

1. 选数据根（默认本机，可改）；
2. 接模型（本机／自备 key／我方云，三选一）；
3. 扫 agent（本机席／CLI／云 API／云 VM，先看见）；
4. 设门（保守默认：低风险自动、中风险问、高风险必问）；
5. 第一件：一句话办一件小事，走完「派→收→验→账」。

### 3.9 视觉与性能

- 中性底、一侧高对比强调色（状态色：陪伴／办事／审计／风险）；
- 无装饰渐变、无大图、无弹窗雨；
- 中文人话；工程话（路径／行号／令号）只在开发者模式；
- 召出 < 100ms；首屏 < 300ms；无白屏闪烁；
- 键盘全可达；高对比／屏幕阅读器可用。

### 3.10 反例（⛔ 做）

- 40 个 faces 平铺成目录；
- 打开即聊天框；
- 每步一个弹窗；
- 「已受理」冒充「已办」；
- 首屏放路径／行号／变量名；
- 设置当入口；
- 假进度条。

## 4 四个物理入口

| 入口 | 形态 | 关键 |
|---|---|---|
| **桌面窗** | Today 主窗 | 坐下来办事 |
| **托盘＋热键** | Summon | 召之即来，⛔ 找图标 |
| **CLI `pa`** | 同动词 | 开发者／批处理／远程 |
| **API／MCP** | 本机 HTTP／MCP | 别的 agent 把活交给 PA |
| 移动端（后置） | 加密中继 | 收通知／批一件 |

### 4.1 CLI 动词（与 UI 同义）

```
pa today                 今天四行
pa do "…"               一句话办事
pa ask "…"               只商量
pa agents                花名册（状态／成本／边界）
pa ledger --since 1d     查账
pa vault export          导出
pa doors                 看门／一次一码
pa stop                  停
```

- 默认人话；`--json` 给脚本；
- ⛔ 另造一套语义；UI 与 CLI 同动词。

### 4.2 API／MCP

- `pa.task`（收一件）、`pa.status`、`pa.receipt`、`pa.stop`；
- 本机 127.0.0.1；⛔ 默认公网；
- 调用方须在册；⛔ 未在册不调；
- 每次调用落账（谁调的、做了什么）。

## 5 主循环：状态机

```
闲 → 收（一句话／一个文件）
   → 划（一件可办之事；或明书只是聊聊）
   → 选（按卡选人；能力／边界／脆性／成本）
   → 派（带门、预算、回执格式）
   → 盯（进度／花费／卡点）
   → 收（回执／产出／证据）
   → 验（对不对／全不全／可否退）
   → 记（账：谁做／何时／花了多少／动了什么）
   → 报（一句人话 ＋ 一笔账）
   → 闲
```

**任务卡**是这条循环的唯一 UI 载体：

- 头：一句话目标；
- 中：步骤（每步：谁／状态／证据）；
- 尾：结果 ＋ 账 ＋ 可否退；
- 侧：门（风险／出机／预算）。

## 6 信任：四个支柱

**信任 ≠ 多一道门。** 门只是「可控」的可见边缘；信任由四件共同建立：

| 柱 | 含义 | 产品面 |
|---|---|---|
| **可预测** | 同类事，同样处理；不惊喜 | 计划卡 ／ 门 ／ 规则可看 |
| **可核** | 每笔有据，可复算 | 回执 ／ 账 ／ 哈希链 ／ 导出 |
| **可退** | 能撤则撤；不能撤提前说 | 撤销 ／ 快照 ／ 确认 |
| **可控** | 你能改、能停、能收权 | 三档 ／ 一次一码 ／ 一键停 |

⇒ **信任 =（可预测 × 可核 × 可退 × 可控）÷ 意外**。

### 6.1 为什么「多一道门」会失败

- 每步都问 ⇒ 用户不看就点「允许」⇒ 门形同虚设；
- 门在流程外 ⇒ 多一次跳转 ⇒ 用户烦；
- 门不给理由 ⇒ 用户不知道怎么选；
- 门不可学 ⇒ 同样的事问一百次。

**好门的三条**：只在风险处出现；嵌在任务卡里；一次决定可复用（带范围与期）。

## 7 五级自主（门的分级）

| 级 | 例 | 默认 | UI |
|---|---|---|---|
| **L0 只读** | 查文件、查网页、读账 | 自动 | 不打扰；账里一行 |
| **L1 可逆本地写** | 改本机文件（有快照） | 自动 ＋ 可撤 | 完成后一行「可撤」 |
| **L2 外部副作用** | 发邮件、调云 API、起云 VM | **先方案，一键批** | 任务卡上「批／改／否」 |
| **L3 不可逆／高风险** | 删、付款、发布、外发私密 | **每次必问 ＋ 一次一码** | 独立确认，带因与果 |
| **L4 禁止** | 绕过安全、泄露密钥 | **⛔ 做** | 直接拒，说明由 |

### 7.1 门是策略，不是弹窗

- 门有**范围**（哪些动作／哪些数据／哪些 agent）、**期**（一次／今天／这个项目）、**预算**（钱／token／时长）；
- 「一直允许」须**带范围**，可在 Doors 里查看与撤销；
- 批量批准：同一任务的多步，一次看全，一次批；
- 一键停：任何时刻，1 秒内停所有在跑。

### 7.2 挣来的自主（earned autonomy）

- 新用户：保守（L1 自动，L2 问，L3 必问）；
- 有战绩：同类任务连续成功、无事故 ⇒ 可**逐域**升到 L2 自动；
- 出一次事故 ⇒ 自动降级，回到问；
- 用户可随时手动升降；⛔ 全局「信任我」开关。

⇒ **信任是挣的，不是装的。**

## 8 证据：回执与账

### 8.1 回执七问

每件必答：**做了什么 ／ 凭什么 ／ 谁做的 ／ 花了多少 ／ 动了什么 ／ 出了什么机 ／ 可否退**。

### 8.2 账本

- 追加写；每条含前一条哈希 ⇒ **改一条，后面全变**；
- 可导出 JSON／PDF；可外部审计；
- 界面只显人话摘要；「看证据」一键展开。

### 8.3 反自报

- ⛔ 以 agent 自报「成功」为成功；
- 须有产出实体（文件／回执／截图／端点回）＋ 复算；
- 验不过 ⇒ 记「未证」，⛔ 记「已成」。

## 9 私密：保险库与出机

| 级 | 内容 | 默认 |
|---|---|---|
| L1 公开 | 可出机 | 自动 |
| L2 内部 | 可出机，记账 | 自动＋账 |
| L3 私密 | 逐次授权 | 门 |
| L4 绝密 | 密钥／身份／隐私 | ⛔ 出机 |

**出机四问**：出什么 ／ 给谁 ／ 为什么 ／ 多久删。

- 密钥：OS 凭据库；⛔ 入 prompt／日志／事件；
- 身份：本机单例；⛔ 多用户；
- 导出／删除：一键，真删；
- 云侧：默认不存用户数据；同步默认关。

## 10 管理「伪 PA」（大厂 agent）

大厂给的是**云端个人 agent**：能力在云、数据在云、钥匙在云。PA 不与之争「更聪明」，PA 做它们的**主人端**：

| 大厂 agent | PA 怎么管 |
|---|---|
| ChatGPT／Claude／Codex | 当外部 agent 登记：卡（能力／边界／脆性／成本）＋ 出机明书 ＋ 回执 |
| 云 API | 密钥在本机；按任务选模型；计量；⛔ 长钥入云 |
| 云 VM | 起停有账；快照可回；数据边界；用后销毁 |
| 云端「记忆」 | ⛔ 当唯一真源；PA 本机账为真，云端只作副本 |

**一句话**：**PA 是伪 PA 的客户，不是它们的对手。** 用户信 PA，不是因为 PA 比它们聪明，而是因为 **PA 握着钥匙、握着上下文、握着账**，能证明它们做了什么，也能随时换掉它们。

## 11 信任指标（可量）

| 指标 | 目标 |
|---|---|
| **意外率**（用户没预期的动作 / 总动作） | < 1% |
| **推翻率**（用户改／否 / 总批） | 可见、逐季降 |
| **撤销成功率** | 100%（可撤类） |
| **事故数**（出机／误删／越权） | 0 |
| **审批等待** | 中位 < 10s |
| **审计查看率** | 周活用户 ≥ 30% |
| **自报 vs 复算差** | 0 |

## 12 反模式（信任杀手）

1. 安装即要「全部允许」；
2. 每步弹窗；
3. 隐藏出机；
4. 假进度／「已受理」；
5. 「请信任我们」式品牌话；
6. 遥测；
7. 自报成功；
8. 不可导出／不可删；
9. 模型锁定；
10. 把「门」做成设置页里的开关，而不是任务卡里的一次决定。

## 13 落地序（与建议书对齐）

| 期 | 窗 | 信任 |
|---|---|---|
| Phase 0（2 周） | 不做新窗；②v1 收口 | 不改门 |
| Phase 1（3–6 周） | Today v1 ＋ 命令带 ＋ Now 右栏 | Vault／Doors／Ledger v1；L0–L3 门 |
| Phase 2（6–10 周） | Agents 只读 ＋ Focus 任务卡 | 回执七问 ＋ 哈希链 |
| Phase 3（10–14 周） | Audit 全宽 ＋ 导出 | 外部审计 ＋ 挣来的自主 |

**v1 范围（窗）**：Today ＋ 命令带 ＋ Now ＋ Focus；Agents／Ledger／Vault／Doors **只读**；⛔ 五个大页面一次做全。

## 15 收尾

**窗是仪表盘：一屏说清今天；账是信任：每笔可核；门只在风险处出现。**

用户不会因为 PA「多问一句」而信任它；用户会因为 **「它做的事我能看见、能复算、能撤、能停」** 而信任它。
