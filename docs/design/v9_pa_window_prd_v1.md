## 3 四个形态

### 3.1 Summon

| 项 | 值 |
|---|---|
| 尺寸 | **520 × 84**（含 1px 边） |
| 位置 | 水平居中；顶距 **18vh** |
| 圆角 | 14 |
| 背景 | `--card` ＋ 1px `--border` |
| 阴影 | `0 20px 60px rgba(0,0,0,.55)` |
| 输入 | 15px；行高 22；左内边距 16 |
| 芯片 | 11px；高 22；圆角 999 |
| 动作 | Enter 发；Esc 收；拖文件进；Ctrl+V 贴图 |

布局：

```
┌──────────────────────────────────────────────┐
│  说一句话，或拖一件东西进来…          [陪][办][查] │
│  ⏎ 发 · Esc 收 · 附件 0                     │
└──────────────────────────────────────────────┘
```

**行为**：召出 < 100ms；无白屏；Esc 收起但**保留草稿 5 分钟**；热键再按恢复。

### 3.3 Focus（一件事在跑）

- 中栏变 **720 宽任务卡**；背景 `rgba(0,0,0,.35)` 轻压；
- 卡内：目标（20px）／步骤（14px）／当前步／进度／花费／停；
- 右栏保留「待你批」「将出机」；
- 完成：卡底出「回执」；Esc 回 Today。

### 3.4 Audit（查账）

- 全宽时间线；行高 44；左时间 11px；中动作 13px；右成本／哈希；
- 筛选：人／agent／风险／出机／成本；
- 展开：七问 ＋ 前一条哈希 ＋ 导出。

### 4.1 顶带

| 元素 | 规格 | 状态 |
|---|---|---|
| 主人 ／ 本机 | 13px；左侧 12 内边距 | 固定 |

| 停 | 32 × 32；红边；hover 红底 | 有在跑才亮 |

### 4.2 左栏

- 5 个 48 × 48 按钮；图标 20；标签 10；
- 选中：左 2px `--blue`；背景 `rgba(88,166,255,.08)`；
- 快捷键 `Alt+1`–`Alt+5`；旧 faces 收进「更多」。

### 4.3 Today 卡

| 项 | 规格 |
|---|---|
| 卡 | 背景 `--card`；边 `--border`；圆角 10；内 14 |
| 标题 | 11px；字距 1.2；`--sub`；大写感 |
| 数 | 24px；`--text`；tabular-nums |
| 行 | 13px；高 24；左文右时；超 3 行「还有 N 件」 |
| 空 | 「—」＋ 一句人话；⛔ 空白 |
| hover | 边 `--blue`；cursor |

四卡内容：

1. **该办**：今天要办；最多 3 行；行＝标题＋截止＋谁；
2. **在等**：谁在等你；行＝人名／agent＋等多久；
3. **在跑**：任务＋进度＋花费；行可点开 Focus；
4. **要拍**：风险＋一句方案；行可点开审批卡。

### 4.5 Now 右栏

| 块 | 高 | 内容 |
|---|---|---|
| 标题 | 28 | 11px；字距 1.2 |

### 4.6 任务卡（Focus）

- 底：结果 ／ 回执 ／ 可否退；
- 右：停 ／ 催 ／ 看证据。

### 4.7 回执卡

1. 做了什么；2. 凭什么；3. 谁做的；4. 花了多少；5. 动了什么；6. 出了什么机；7. 可否退。

## 8 验收用例（Given／When／Then）

1. **召出**：Given 任意前台；When 按 `Ctrl+Shift+Space`；Then Summon < 100ms 出现，焦点在输入框。
2. **收起**：When Esc；Then 收起且草稿保留 5 分钟；再按恢复。
3. **四卡**：Given context／runs／threads／approvals 有数；Then 四卡数与端点一致；空卡显「—」＋ 人话。
4. **发一件事**：When 输入「把上周的账导一份」＋Enter；Then 出计划卡；⛔ 直接执行。
5. **L2 批**：When 点「批」；Then 任务开始，右栏在跑 +1，账预记一行。
6. **L2 否**：When 点「否」；Then 任务取消，账记「已否」，⛔ 执行。
7. **L3 码**：Given 高风险；When 未输码点「批」；Then 拒绝；输对 6 位码；Then 执行；错码 3 次锁 5 分钟。
8. **停**：Given 在跑；When `Ctrl+.`；Then ≤1s 停，状态「已停」，账记。
9. **回执**：When 任务完成；Then 回执七问齐；有 sha16；可导出。
10. **账**：When 打开 Ledger；Then 每行有前一条哈希；展开可复算；导出 JSON。
11. **Agent 只读**：When 打开 Agents；Then 四类（席／CLI／云 API／云 VM）皆列；缺者显「未接」。
12. **出机**：Given 涉云；When 发前；Then 显「出什么／给谁／为什么／多久删」；⛔ 静默。
13. **离线**：Given 断网；Then 本地卡可用；云侧灰；⛔ 假可用。
14. **误操作**：When 拒绝后；Then 焦点回输入框；⛔ 弹窗雨。
15. **工程话**：When 首屏；Then 无绝对路径／行号／令号／变量名（正则核）。
16. **键盘**：When 只用键盘；Then 可达四卡／命令带／审批／停；焦点可见。
17. **回归**：When 关 feature flag；Then 旧三面照常；⛔ 白屏。
18. **窄屏**：Given 1024；Then 四卡变 1 列；右栏可收起；无横向滚动。
19. **首跑**：Given 新装；Then 五步 ≤5 分钟；可跳过；数据根可改。
20. **遥测**：Then 默认 0 上报；出机 0 项时明书「无」。
