> 呈：老板｜作：DSH（老板 PA）｜2026-10-27

---

## 0 一句话

**PA 是一位主人的本机主权私人 agent：它持有你的世界，替你调度你所有的 agent，每笔动作可查、可停、可退，钥匙在你手里。**

四件不可替代：**你的上下文（数据主权）· 你的手（替你行动）· 你的账（可审计）· 你的门（授权在你）**。

---

## 1 定义：PA 是什么，不是什么

### 1.1 本质（承早期定义，补第四件）

早期定义：**把你的「上下文」变成「可执行的行动」的本机私人运营体**（上下文主权 × 积累 × 行动）。

本建议补第四件：**账**。没有账，主权不可证；没有账，行动不可信；没有账，订阅不成立。

⇒ **PA ＝ 上下文主权 × 持续积累 × 替你行动 × 可审计**。

### 1.2 五个不可替代

| # | 不可替代 | 一句话 |
|---|---|---|
| 1 | **你的世界** | 台账／记忆／画像／文件／历史决定，全在你本机；别人模型再强，没有你的世界 |
| 2 | **你的手** | 不只是答，而是真动手：文件／命令／浏览器／桌面／CLI／云 API／云 VM |
| 3 | **你的账** | 每笔：谁派的／谁做的／花了多少／动了什么／可否退 |
| 4 | **你的门** | 哪些它自己做／哪些要问你／哪些绝对不做；一键停 |
| 5 | **你的钥匙** | 私密信息、密钥、身份，归你；可导出、可删除、可离线 |

### 1.3 不是什么（防走偏）

1. ⛔ 不是「又一个聊天框」——聊天只是入口之一，不是产品；
2. ⛔ 不是 SaaS 面板——数据与手在本机；云只做模型／更新／可选同步；
3. ⛔ 不是多用户协作平台——**一位主人**；多用户会把权限与审计带偏；
4. ⛔ 不是「模型更强」的生意——模型随时可换；卖的是积累、产出、主权；
5. ⛔ 不是「什么都自己实现」——手可借、脑可借、班子可借；**管理／门／账／红线自己长**。

### 1.4 与市面形态的生态位

| 形态 | 它有 | 它没有 |
|---|---|---|
| ChatGPT／Claude | 强脑、通用问答 | 你的世界、你的手、你的账 |
| Cursor／Claude Code／DSH | 替你干某个域的活 | 你的经营上下文、跨 agent 调度、主权审计 |
| Paseo／Orca | 编排 agent、开发者工作台 | 面向主人的入口、私密信息、本地审计 |
| Obsidian／Notion | 你的资料 | 不替你办事 |
| Ollama／LM Studio | 数据不出机 | 没有积累、没有产出、没有账 |

⇒ PA 的生态位：**「你的世界 ＋ 替你行动 ＋ 可查的账」三件同时具备，且只属于一个人。**

## 2 用户与场景

### 2.1 三类用户

| 用户 | 痛 | PA 首件 |
|---|---|---|
| **一个人**（净机） | 一堆烂事，只有 PA 一个 agent | 今日一屏 ＋ 一本台账 ＋ 一道门 |
| **OPC 一人公司** | 一人多岗：客户／交付／对账／内容／行政 | 一人公司开工包：一窗 ＋ 台账 ＋ 3 个岗位 agent |
| **企业岗位** | 已有模型，缺「管得住、查得清、成体系」 | 岗位 agent 工厂：工作流 ＋ 交付物 ＋ 验收 ＋ 审计 |

### 2.2 三类日常

1. **陪伴**：记得你、懂语境、陪你说、**不擅自动手**；
2. **办事**：一句话 → 计划 → 派给合适的 agent → 收 → 验 → 记账；
3. **审计**：今天做了什么、花了多少、动了哪些件、什么出了机、可否退。

### 2.3 四个关键瞬间（主权的硬验收）

- **数据不出机**：默认不出；要出，先给你看「出什么、给谁、为什么」；
- **可停**：一键停，正在跑的 agent 在 1 秒内停；
- **可退**：能撤的撤，不能撤的提前说；
- **可带走**：全部数据可导出，换机可恢复，⛔ 锁定。

### 3.3 六个真缺口

1. **入口碎**：40 个面，用户不知道从哪开始；没有「一句话就办」的唯一入口；
2. **无保险库**：私密信息／密钥／身份没有端到端加密、分级、导出、删除；
3. **无出机明书**：什么出了机、给谁、为什么，界面不可见；
4. **无动作级门**：只有端点守卫与三档权限，缺「这一次、这个动作、这个数据」的授权；
5. **无云 VM 适配**：只有本机席／CLI／云 API；云 VM 的起停、快照、数据边界、成本未接；
6. **无哈希链审计**：台账可查，但不可证「未被改」；缺导出报告与外部审计接口。

## 4 产品形态与入口（本建议的核心）

### 4.1 一个主入口：Today

**Today ＝ 用户打开 PA 的第一屏**，只回答四件事：

1. **今天要办什么**（人话，不是工程号）；
2. **谁在等我**（人／agent／审批）；
3. **正在跑什么**（进度、花费、可否停）；
4. **要我拍什么**（一件一件，带默认建议）。

Today 下面 **一个输入框**：说话就完（Enter 即发）。⛔ 功能目录、⛔ 设置迷宫、⛔ 工程话。

### 4.2 一条主循环

```
一句话
  → PA 收成「一件可办之事」
  → 计划（件／序／依赖／尺／期）
  → 选人（本机席／CLI／云 API／云 VM）
  → 派（带门、带预算、带回执）
  → 盯（进度、花费、卡点）
  → 收（回执、产出、证据）
  → 验（对不对、全不全、可否退）
  → 记账（谁做、何时、花了多少、动了什么）
  → 回你一句人话 ＋ 一笔可查的账
```

### 4.3 五个面（不是五个 Tab，是五个问题）

| 面 | 回答 | 关键交互 |
|---|---|---|
| **Today** | 我现在该知道什么 | 四行 ＋ 一个输入框 |
| **Agents** | 谁能干、在干什么、花多少 | 花名册 ＋ 状态 ＋ 一键停 |
| **Ledger** | 发生了什么、可否退 | 时间线 ＋ 证据 ＋ 导出 |
| **Vault** | 什么是私密的、出没出机 | 分级 ＋ 加密 ＋ 导出／删除 |
| **Doors** | 什么允许、什么要问、什么禁止 | 三档 ＋ 一次一码 ＋ 一键停 |

### 4.4 四个物理入口（召之即来）

| 入口 | 形态 | 场景 |
|---|---|---|
| **桌面窗** | Electron 壳（主） | 坐下来办事 |
| **托盘 ＋ 全局热键** | 随时唤出 | 正在用别的软件，一句话派活 |
| **CLI：pa** | 命令行 | 开发者／批处理／远程 |
| **API／MCP** | 本机 HTTP／MCP | 别的 agent 把活交给 PA |
| **移动端**（后置） | 加密中继 | 不在电脑前，收通知／批一件 |

### 4.5 入口六原则

1. **召之即来**：热键／托盘，⛔ 找图标；
2. **意图优先**：一个框，⛔ 先选功能；
3. **一屏**：Today 一屏说清；
4. **不导航**：⛔ 三级菜单；深度内容用「更多」门后；
5. **可信提示**：出机前给「出什么／给谁／为什么」；
6. **可停**：任何时刻一键停，1 秒内生效。

### 4.6 反面清单

- ⛔ 把 40 个 faces 平铺成功能目录；
- ⛔ 首屏放工程话（路径／行号／令号／变量名）；
- ⛔ 用「已受理」冒充「已办」；
- ⛔ 把「设置」当入口；
- ⛔ 多用户／协作把单主人模型带偏。

## 5 能力模型（六层）

与早期「三层」对齐：**讨论层（陪伴）／筹划层（计划物）／执行层（手）**；本建议在其下补**三层底座**（L0 数据／L1 门／L2 账），在其上补**入口**（L5）。

| 层 | 名 | 内容 | 现状 | 缺口 |
|---|---|---|---|---|
| L0 | **数据主权** | 保险库、分级、加密、导出、删除 | 散件 | 端到端未证 |
| L1 | **身份与门** | 单主人、三档、一次一码、一键停 | permission／owner_guard／grants | 动作级门 |
| L2 | **账本** | 哈希链、回执、成本、可退 | 台账／回执／印 | 哈希链、导出报告 |
| L3 | **调度** | 花名册、选人、派、盯、收、验、催 | roster／invoke／dispatch | 闭环、云 VM、成本 |
| L4 | **执行** | 文件／命令／浏览器／桌面／CLI／云 API／云 VM | 本地＋CLI＋API | computer use、云 VM |
| L5 | **入口** | Today／Agents／Ledger／Vault／Doors | 40 faces | 唯一主入口 |

## 6 多 agent 编排（用户的核心要求）

### 6.1 四类 agent 与适配器

| 类 | 例 | 适配器 | 关键 |
|---|---|---|---|
| **本机席** | Paseo f202f89／b136893… | LocalSeatAdapter（paseo agent send） | 状态、回执、超时 |
| **CLI** | codex／claude／dsh | CliAdapter（起进程、PTY、超时） | 非交互、stdin、抓取 |
| **云 API** | OpenAI／Anthropic／DeepSeek | CloudApiAdapter（base_url＋key） | 密钥不落面、计量 |
| **云 VM** | SSH／远程 agent | CloudVmAdapter（起停、快照、销毁） | 数据边界、成本、回滚 |

### 6.2 统一卡（七键）

每张 agent 卡：`capabilities` ／ `boundary` ／ `fragility` ／ `cost` ／ `invoke` ／ `probe` ／ `verified`。

- `boundary` 与 `fragility` **必填**：只写能力的卡会误导派活；
- `verified` 须有实测读数与刻；⛔ 写「应该可以」；
- `invoke` 逐字（命令／端点／SDK）；`probe` 一次最小调用。

### 6.3 调度器七步

1. **收**：把话收成一件可办之事（或明书「只是聊聊」）；
2. **划**：件／序／依赖／尺／期；
3. **选**：按卡选人（能力 ／ 边界 ／ 脆性 ／ 成本）；
4. **派**：带门、带预算、带回执格式；
5. **盯**：进度、卡点、成本；
6. **收**：回执、产出、证据；
7. **验记**：对账（台账 ⟷ 盘上 ⟷ 你所说）＋ 记账 ＋ 人话回报。

### 6.4 云 VM 的特别纪律

- **起停有账**：谁起的、什么配置、花了多少、何时销毁；
- **数据边界**：什么可以上 VM、什么⛔；上之前给出机明书；
- **快照与回滚**：改坏了能回；
- **默认最小**：不用就销毁；⛔ 常开烧钱；
- **密钥不入 VM**：用短时令牌，⛔ 长钥。

### 6.5 人在环

| 风险 | 例 | 门 |
|---|---|---|
| 低 | 读文件、查资料 | 自己做，记账 |
| 中 | 改文件、发邮件 | 先给方案，一键批 |
| 高 | 删、付款、发布、外发 | **每次必问**，一次一码 |
| 禁止 | 绕过安全、泄露密钥 | **⛔ 做** |

### 6.6 反例（⛔ 做）

- ⛔ 不问就派高风险活；
- ⛔ 只看「成功」不看产出；
- ⛔ 不回执、不记账；
- ⛔ 用「同号件在」当回执（本项目的真教训）；
- ⛔ 一个 agent 报「我做了」就信。

### 6.7 从「管 Paseo 15 席」到「管一切」

我现在管 Paseo 的 15 席：发、收、催、记、验。把这套抽象出来，就是 PA 的调度层：

- **席** → 任何 agent；
- **投一步** → 任何派活通道；
- **回执** → 任何产出；
- **台账** → 任何账；
- **门** → 任何风险。

⇒ PA 不是「再做一个 Paseo」，而是**把 Paseo 的管理能力装进用户电脑，面向一位主人**。

## 7 主权与安全（护城河）

### 7.1 数据分级与出机明书

| 级 | 内容 | 默认 |
|---|---|---|
| L1 | 公开 | 可出机 |
| L2 | 内部 | 可出机，记账 |
| L3 | 私密 | **逐次授权**，明书 |
| L4 | 绝密（密钥／身份／隐私） | **⛔ 出机** |

出机明书四问：**出什么 ／ 给谁 ／ 为什么 ／ 多久删**。

### 7.2 审计链

- 每条：时／人／agent／动作／对象／结果／成本／证据／前一条哈希；
- **哈希链**：改一条，后面全变；
- 可导出（JSON／PDF）；可外部审计；
- 可退：能撤的撤，不能撤的提前说。

### 7.3 私密信息

- 密钥：OS 凭据库（DPAPI／Keychain），⛔ 入 prompt／日志／事件；
- 身份：本机单例，一位主人；⛔ 多用户；
- 隐私：分级、脱敏、最小化；
- 导出／删除：一键，真删（⛔ 假删）。

### 7.4 威胁模型

| 威胁 | 对策 |
|---|---|
| Prompt injection（网页／邮件／文件） | 外部内容⛔ 当指令；工具调用须门；高风控 |
| 恶意 agent | 卡＋边界＋沙箱＋最小权限＋可停 |
| 供应链（npm／pip／插件） | 签名、锁版本、沙箱、审计 |
| 云端泄露 | 默认不出机；出机明书；短时令牌 |
| computer use 误操作 | 只读先、逐次授权、截图留证、可回滚 |
| 模型厂商变更 | 模型抽象层，可换；⛔ 锁定 |

### 7.5 红线

1. ⛔ 遥测；2. ⛔ 静默上传；3. ⛔ 默认 bypass；4. ⛔ 密钥入面；5. ⛔ 模型锁定；6. ⛔ 假删；7. ⛔ 把「已受理」当「已办」。

## 8 架构建议

### 8.1 本机核心（现有 Python／Flask 演进）

```
core/pa/
  vault/          保险库（分级、加密、导出、删除）
  policy/         门（三档、一次一码、预算、红线）
  ledger/         账（哈希链、回执、成本、可退）
  registry/       花名册（卡、探测、健康、成本）
  orchestrator/   收→划→选→派→盯→收→验→记
  adapters/       seat / cli / mcp / cloud_api / cloud_vm
  entry/          today / agents / ledger / vault / doors 的只读投影
```

### 8.2 适配器接口（统一）

- `probe()` → 活没活、版本、读数；
- `invoke(task, budget, receipt_schema)` → 回执；
- `status()` → 进度、成本、卡点；
- `stop()` → 1 秒停；
- `snapshot()/rollback()`（云 VM）；
- `egress()` → 这次要出什么。

### 8.3 云侧最小

- 模型路由（本机／我方／自备 key，一处定形）；
- 更新（增量、签名）；
- 可选同步（端到端加密，默认关）；
- 计量／订阅（只对云侧消耗）；
- **不存用户数据**（除用户显式选择同步）。

### 8.4 前端

- Electron 壳（已有）；⚠ 早期文件主张 PyWebView（壳近零、+0.4–0.5 GB 之差）⇒ 建议 v9.1 前做 **2 天 spike**（启动／内存／更新／签名）再定，⛔ 现在翻烧饼；
- Today 主入口；Agents／Ledger／Vault／Doors 四个面；
- 现有 40 faces **不删**，**收进「更多」门后**；
- 工程话（路径／行号／令号）只在「自述／自检／开发者」；
- 移动端后置（加密中继）。

### 8.5 数据

- 本地 SQLite ＋ JSONL 混合：结构化查询用 SQLite，事件流用 JSONL；
- 账本哈希链；
- 保险库加密（OS 凭据＋文件加密）；
